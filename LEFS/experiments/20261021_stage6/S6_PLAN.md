## 1 三个硬约束（先接受，再设计）

### 1.1 摩擦传递扭矩可能不够（最大风险）

| 量 | 值 | 来源 |
| --- | --- | --- |
| 夹爪额定夹持力 | 40 N（最大 50 N） | 官方参数 §2.3 |
| 瓶盖半径 | ~15 mm（30 mm 盖） | 实测 |
| 指面材料 | 光滑金属/硬塑 | 实测 |
| μ 假设 | 0.5 ~ 0.6 | 塑料-金属干摩擦 |
| **可传递扭矩** | `M = 2·μ·F·r` = **0.60 ~ 0.72 N·m** | 计算 |
| 未开封盖开启扭矩 | **1.0 ~ 1.8 N·m** | 行业经验值，**必须实测** |

**结论**：μ 至少要到 0.8~1.0 才够，靠原装指面不行。

**对策（按性价比排序）**：
1. **指面贴 1~2 mm 硅胶/橡胶皮**（双面胶固定）→ μ 提到 1.0+，传递扭矩翻倍到 ~1.4 N·m。成本几块钱，最有效。
2. **夹在盖的竖纹区**而不是光滑顶面 —— 竖纹提供形状锁合，不纯靠摩擦。
3. **冲击式松动**：夹住后小幅快摆 ±10° @ 3~5 Hz，模拟人手"拧-松-拧"，把静摩擦突破拆成多次小幅，降低峰值需求。
4. 兜底：换开启扭矩小的品牌，或用温水泡盖 30 s（PET 盖受热膨胀，开启扭矩下降 20~30%）。

### 1.2 J6 一段拧不完一整圈

- 手册 V1.1.0 写 J6 ±120°；本项目 0x473 实测回读曾见单侧 0~343°。**一律以回读为准，不硬编码**。
- 未开封盖需 1.5~2 圈（540~720°）。
- 按 ±120° 保守算，每段净推进约 106° → 需 7 段；按 343° 算每段 286° → 3 段。
- **必须做棘轮**：转满 → 张开 → 回位 → 重新闭合并继续。回位时若夹爪没真张开，会把盖子拧回去甚至拧坏。

### 1.3 J6 的 K 尚未标定，但**可以补标**（不缺方法，缺扭矩源）

**阶段 2 的真实结论**（`calibration/k_table_free.json`）：

```
"J6": { "state": "未标定", "K": null,
        "reason": "水瓶质心几乎在工具轴（=J6 转轴）上 ⇒ τ6≈0；需偏心横杆 80 mm" }
```

- 段 2 的 K 只标出 J2=3.94~4.72、J4=0.68、J5=0.63（组约束后 J2=J3、J4=J5）。
- **J6 未标定的根因不是方法错，是几何没激励**：水瓶质心横偏只有 5.3 mm，
  `τ6 = m·g·e` ⇒ 全程跨度仅 **0.054 N·m**，比噪声地板 **0.111 N·m** 还小一半。
- `s21_group_fit.py` 把 J6 放进自由拟合是能出数的，但 `σ_K/K = 21%`
  （对比 J2 5%、J3 3.6%），误差大一个量级，不能用于绝对扭矩。
- J1 同理但**连信号都没有**：重力与 J1 轴平行 ⇒ `τ1 ≡ 0`，静态法结构性无解。

**补救办法：给它一个绕自身轴的切向力源**

最省事的做法不是弹簧秤（力不稳定、要人手稳），而是**悬挂配重**：
`τ = m·g·L`，力永远竖直向下，扭矩精确已知，全程没人碰机械臂。

力臂 L 靠"夹爪夹一根扁平横杆"放大到 100 mm（纯用指尖只有 35 mm，信号不够）：

| 配重 m | τ @ L=100mm | 相对当前 0.054 | 相对噪声 0.111 |
| --- | --- | --- | --- |
| 0.20 kg（200 ml 水） | 0.196 N·m | 3.6× | 1.8× |
| 0.30 kg（300 ml 水） | 0.294 N·m | 5.4× | 2.6× |
| 0.40 kg（400 ml 水） | 0.392 N·m | 7.3× | 3.5× |
| 0.50 kg（500 ml 水） | 0.490 N·m | 9.1× | 4.4× |
| 0.60 kg（600 ml 水） | 0.588 N·m | 10.9× | 5.3× |

5 个质量点拟合 `τ = K6·I6 + b`（b 为常数摩擦偏置 + 横杆自重，**不可省**）。
0.6 kg 时信噪比约 5，够用；再往上会逼近末端负载 1 kg 上限，且 J6 可能顶不住，不划算。
**用同一个瓶子加水就能覆盖这 5 个点**，不需要任何标准砝码。

**注意三条**：
1. 必须是**切向**（力垂直于 J6 轴、且垂直于力臂）。轴向顶、径向推都不产生绕轴力矩 ——
   横杆竖直朝下挂砝码就是典型的零力矩陷阱，读数正常但全是废的。
2. J6 保持在位置控制 + 使能，靠位置环的补偿电流反映扭矩；同时记录 J6 被拉走的**位置偏移**。
3. 从小往大加，**上限 0.8 kg @ 100 mm**，不要一上来就拉满，避免触发过流失能。
4. 横杆必须**扁平**。圆杆会在夹爪两指间自转，力根本传不到 J6。

**对拧瓶盖任务的影响**：

- 只判"什么时候脱开" → **不需要 K6**，电流突降就够。
- 要报 τ-θ 曲线的物理单位、写进报告 → **需要 K6**。
- 建议顺手补，因为它是纯工装活、不碰瓶子，和 S6-0 互不依赖，可以两个人在两张桌子上同时做。

**在 K6 补出来之前，J6 力矩只能用这三种替代口径**：
J6 电流作**阻力代理量**（同姿态相对可比）、SDK `effort` 字段作**量级参考**、
J4/J5 反扭矩作**旁证**（拧盖时腕部会被反推）。

> **别做的事**：不要用 SDK 的 `effort` 字段当 J6 绝对扭矩。阶段 2 已证明厂商那个换算系数
> 是**分组统一常数**（J1–J3=1.18125、J4–J6=0.95844），对 J2/J3 小 4 倍、对 J4/J5 大 0.78 倍，
> J6 的真实偏差未知。

## 2 五步实施

### S6-0 量出这只盖子的真实开启扭矩（人力，5 分钟，先做）

**为什么先做**：这是决定整个方案成败的唯一数字。测出来 1.8 N·m 而只能传递 0.72 N·m，后面所有代码都白写。

做法：瓶身台钳固定，瓶盖侧面贴一小段胶带留出施力点，弹簧秤（或数显拉力计）挂住、水平拉动，读出盖开始转动的最大力 F。
`M = F × r`，r = 力作用点到盖中心的水平距离。

产出：`s6_cap_torque.md`（记录 3 次取最大）

**判据**：若 M ≤ 0.6 N·m → 原装指面直接能拧；若 M ≥ 1.0 N·m → 必须先做指面增摩。

> **注意**：这一步是纯人力测量，机械臂不参与（瓶盖夹在台钳上，臂没碰它），
> 所以**读 J6 电流没有意义**，K6 标定是独立的一步，见 S6-0.5。

### S6-0.5 补标 K6（挂配重，约 20 分钟）

> **✅ 已完成（2026-10-22 11:10）：K6 = 10.79 ± 0.50 N·m/A，σ/K = 4.6%，R² = 0.9958，判据通过。**
>
> **但方法被换掉了**：本节下面的「挂配重静态保持」在原理上成立、实测**无效**。
> 100 / 200 / 400 ml 三点力矩涨了 4 倍，I6 反而从 +0.054 掉到 +0.019 A ——
> 根因是 K6 太大（10.8 N·m/A），0.18 N·m 只需 **0.017 A**，完全淹没在 0.03 A 的噪声里。
> **真正有效的是「正反转动差分法」**，见本节末尾「实测有效的方法」。

**为什么**：见 §1.3。J6 现在的 `τ6` 跨度 0.054 N·m 低于噪声地板 0.111 N·m，
不补标，τ-θ 曲线的纵轴只能写成"电流"而不是"N·m"。

**方案：悬挂配重产生已知扭矩**，不用弹簧秤、不用人手稳住力。
`τ = m·g·L`，力自然竖直向下，只要几何对，扭矩就是精确已知的。

#### 必备工装（都是家里有的）

| 件 | 要求 | 说明 |
| --- | --- | --- |
| 横杆 | 扁平、轻、刚性，250~300 mm | 木尺 / 铝条 / 钢板尺。**扁平截面**是关键：圆杆会在夹爪里自转，圆杆等于白做 |
| 配重 | 5 个质量点，0.2~0.6 kg | **不需要标准砝码**，装水的瓶子就行，见下面的替代方案 |
| 悬挂点 | 距法兰中心 **L = 100 mm** | 卷尺量，胶带做标记。**L 是主要误差源，量到 ±1 mm** |

#### 配重从哪来（**已选定路线 2：量水；1 和 3 留作备选**）

关键点：这里需要的不是"砝码"，是**一个质量已知的重物**。砝码只是最方便的一种。

**路线 1（备选）：有厨房秤**
任何重物都行 —— 装水的瓶子、米袋、哑铃片、厚书、洗衣液。称一次，把重量输进脚本。
**同一个瓶子反复加水**最方便：从 0.2 kg 加到 0.6 kg，5 个点，一个容器搞定。
（家里已有现成的：阶段 2/5 一直用的那个 **0.525 kg 水瓶**。）

**路线 2：用刻度瓶量水（已选定）**

水在 20 ℃ 的密度是 **0.9982 g/ml**，体积直接换质量。矿泉水瓶身就有 ml 刻度。

| 刻度读数 | 水质量 | τ @ L=100mm | 相对原信号 0.054 |
| --- | --- | --- | --- |
| 200 ml | 0.1996 kg | 0.1958 N·m | 3.6× |
| 300 ml | 0.2995 kg | 0.2937 N·m | 5.4× |
| 400 ml | 0.3993 kg | 0.3916 N·m | 7.3× |
| 500 ml | 0.4991 kg | 0.4894 N·m | 9.1× |
| 600 ml | 0.5989 kg | 0.5873 N·m | 10.9× |

> **关键简化：空瓶和绳子的重量完全不用称。**
> 它们产生的力矩是**常数** `m_bottle·g·L`，在 `τ = K6·I + b` 里全被截距 `b` 吸收。
> 斜率 K6 只由水的质量决定，和瓶重无关。所以哪怕瓶子 25 g 还是 18 g，都不影响结果。
>
> 代价：`b` 会是一个明显非零的数（含横杆自重 + 瓶重 + 摩擦）。**这是预期行为，不是拟合误差。**

**操作要点（八条，错一条数据就偏）**

1. **同一个瓶子从头用到尾**，瓶重恒定才能被 b 吸收。中途换瓶子等于换了一个 b。
2. 瓶子容量 ≥ 600 ml。用 1.5 L 的大瓶刻度太粗，建议 550~700 ml 的瓶，或用厨房量杯。
3. **读数以凹液面最低点为准**，平视。误差控制在 ±10 ml（±10 g，相当于 2%）。
4. **加水后擦干瓶外壁**，别让水滴在采样时掉下去 —— 掉一滴就是一次冲击。
5. 绳长固定：每次都挂在横杆上同一个标记点（胶带做限位），顺带保证 L 不变。
6. 挂上后**确认瓶子不碰桌面、不碰臂身**，自由下垂。力必须竖直。
7. 水在瓶里会晃（周期约 1 s，衰减好几秒）。脚本会自动等 I6 稳定再采样，
   但看到 `[WARN] 没等到稳定` 就要重测这个点。
8. 顺序从轻到重（200 → 600 ml），每点测完把水倒掉重新量，不要"往上加"——
   往上加时你没法确认瓶里剩多少。

**脚本调用**（`--by-volume` 直接输 ml，自动换算）

```bash
python3 s6_k6_calib.py run --arm 0.100 --by-volume --points 5
```

**路线 2 的已知误差源**：刻度读数 ±10 ml（2%）是主要误差，其次才是 L 量测（±1 mm，1%）。
两者合起来约 2.2%，仍低于 5% 判据，可以接受。若想更准，用厨房量杯代替矿泉水瓶。

**路线 3（备选）：什么都没准备，用弹簧秤/行李秤拉**
把秤挂在横杆末端，**竖直向下**缓慢拉，读数值输入脚本。
缺点：人手要稳住 3 秒以上，重复性不如悬挂重物（建议每点测 2 次取均值）。
注意**力必须竖直**，斜拉会引入余弦误差，横杆也会被拽偏。

**路线 3 的变体（不用买秤）**：把矿泉水瓶装满水，用绳子挂在横杆末端，绳子长度固定 ——
这就退化成路线 1/2 了，而且力天然竖直，比弹簧秤稳。**只在连刻度瓶都没有时才用弹簧秤。**

**不推荐的路线：动态法**
用 `τ = I·α` 让 J6 做已知角加速度反推 K6。不需要任何配重，看起来很美，但：
夹爪+横杆的转动惯量算不准、摩擦力矩混在里面分不开、加速度要靠位置微分（噪声放大）。
只能当交叉验证，不能当主口径。

#### 姿态：这个必须用算出来的，别随手摆

`(0, 70, -50, 0, -15, q6)` —— 实测 URDF 结果：

```
J6 轴倾角 = 0.0°    ← 完全水平，与 q6 无关
q6=0   → y 轴 0.0°（水平），x 轴 90.0°（竖直）
q6=90  → x 轴 0.0°（水平），y 轴 90.0°（竖直）
TCP = (+279, 0, +358) mm   净空 222 mm
```

**规律**：只要 **J4 = 0**，J6 轴就恰好水平 —— 这是这台机器的腕部中立位特性。
随手摆的 `(0,45,-60,0,45,0)` 轴倾角 25°，`(0,60,-70,0,30,0)` 是 15°，都不合格。

**横杆水平靠 q6 调**：横杆沿 y 就取 q6=0，沿 x 就取 q6=90。试两次就知道是哪个方向。

#### 拟合与判据

拟合 `τ = K6·I6 + b`（**b 不可省**，它吸收横杆自重和摩擦偏置）。

| 判据 | 门槛 | 含义 |
| --- | --- | --- |
| `σ_K/K` | < 5% | 对齐 J2（5%）/ J3（3.6%）的水平 |
| `R²` | > 0.98 | 线性度；不达标通常是横杆在夹爪里打滑 |
| 残差 RMS | ~0.11 N·m | 与噪声地板同量级 |

自测已通过：合成数据 `K=0.62 / b=−0.03` + 1% 噪声 → 恢复 `K=0.6207`、`σ/K=1.07%`、`R²=0.9997`。

**不达标怎么办**（按顺序试）：`--arm` 加到 0.15 → 加重点到 1.0 kg → 换更扁更硬的杆。

#### 三个已知风险

1. **横杆自转**：圆杆在夹爪里会转，力根本传不到 J6。用扁杆，并在杆和指面之间垫一点砂纸。
2. **J6 被拉偏**：位置环顶不住时 `q6` 会漂。脚本守 `drift > 5°` 就判该点作废并停下。
   真顶不住就把力臂从 100 mm 缩到 60 mm、减重。
3. **电量/使能**：有轴未使能时位置保持是假的，砝码会把臂拽下来。脚本启动就检查 `all(enable)`。

#### 实测有效的方法：正反转动差分

**原理**：不动配重，让 J6 在竖直位来回摆，摩擦随运动反向、负载不反向：

```
正转 I_f = (τ_摩擦 + τ_load)/K6
反转 I_r = (τ_摩擦 − τ_load)/K6
ΔI = I_f − I_r = 2(τ_摩擦 + τ_load)/K6 = (2/K6)·τ_load + const
⇒ K6 = 2 / 斜率        ← 摩擦全进 const，正是它该待的地方
```

**三条必须遵守的做法（每条都踩过一次）**

1. **两段必须扫同一角度的相反方向**：先空跑到 `lo`（不记录），再 `lo→hi`、`hi→lo`。
   第一版从当前中心角出发，两段角度区间不同，钢尺倾斜角不同，空载 ΔI 直接偏 0.155 A。
2. **空载 ΔI 不为零是正常的**，它等于 `2τ_摩擦/K6`，实测 **0.160 A**（反推 τ_摩擦 ≈ 0.86 N·m）。
   把它当"故障"去优化是白费功夫 —— 它本来就是截距。
3. **中心必须放在 q6 = 140°（竖直位）**：此时钢尺水平、力矩全部投影到 J6 轴。
   偏离 15° 要乘 cos(15°) = 0.966，白丢 3.4%。

**参数与硬上限**

| 项 | 值 | 原因 |
| --- | --- | --- |
| 力臂 L | **120 mm** | 185 mm 时 300 ml 就撞 J5 的 3 A（实测 3.06 A） |
| q6 中心 | **140°** | 夹爪竖直、钢尺水平 |
| 摆幅 | ±15° | 再大则钢尺倾斜角变化加剧，cos 修正变复杂 |
| 速率 | 2°/s | 慢一点配重摆动小 |
| **质量×力臂** | **≤ 0.04 kg·m** | 这条姿态下 J5 的硬上限，300 ml×120 mm 刚好过 |

**最终数据（4 点，判据通过）**

| τ (N·m) | ΔI (A) |
| --- | --- |
| 0（空载锚点） | 0.1602 |
| 0.1175（100 ml） | 0.1788 |
| 0.2349（200 ml） | 0.2048 |
| 0.3524（300 ml） | 0.2241 |

斜率 0.1854 ± 0.0085 A/(N·m)，const 0.1593 A，
**K6 = 10.7882 ± 0.4952 N·m/A（σ/K 4.6%，R² 0.9958）**，是厂商分组系数（0.95844）的 **11.26 倍**、J4/J5（0.7446）的 **14.5 倍**。

**对后续拧瓶盖的推论（很重要）**

J6 输出 1~2 N·m 只需 **0.1~0.2 A**，电流上限 3 A 对应约 32 N·m —— **电机永远不是瓶颈**，
电流守卫在这条轴上实际上不会触发。所以将来拧不开时，只可能是：
① 夹爪摩擦传递不足（`2μFr ≈ 0.6~0.72 N·m`）；② 对轴偏心把这个上限再打折。
**不要去怀疑 J6 没劲。**

### S6-1 J6 行程与空载基线

**为什么**：不知道 J6 到底能转多少，棘轮段长就没法定；没有空载电流-角度基线，"多大电流算有阻力"也无从判断。

- 读 0x473 固件限位（**不要用记忆值**）。
- 空载 J6 从安全起点慢速扫到限位前 5°，再回来一次，50 Hz 记录电流 + `effort`。
- 确认三件事：① 真实可用角度；② 接近端点时绝对编码器是否回绕；③ 空载电流随角度是否平稳（若某段偏高，说明该段有减速箱阻力，会污染判据）。

产出：`s6_j6_range.json`、`s6_baseline_J6.csv`

### S6-2 摩擦传递扭矩标定（不打滑的上限）

**为什么**：S6-0 得到"需要多少"，这一步得到"最多能给多少"。两者一减，才知道要不要增摩。

- 夹爪夹住一个**固定不动的圆柱试件**（瓶盖本身即可，瓶身已被台钳锁死）。
- J6 以 3°/s 缓慢加载，同时记录夹爪开度、J6 电流、`effort`。
- **土办法但最可靠**：瓶盖和瓶身上用记号笔画一条对齐线。打滑时两线错开，肉眼一眼可见，比任何算法都准。
- 打滑特征：夹爪开度基本不变、J6 角度在走、但盖子不动 → 摩擦传递达到上限。

产出：`s6_grip_limit.md`（记录 μ_eff = M/(2Fr) 反推值）

### S6-3 对轴 + 单段拧

**对轴（不能省）**：
- 用 `stage2_pose_guard.py` 的 `S.Arm` 正运动学反解一组 q，使 **J6 轴与世界竖直轴夹角 <2°**，TCP 在盖上方 80 mm。
- 过几何闸门：净空 ≥100 mm、TCP z ≥150 mm、路径不降。这条曾在 TCP z=67 mm 撞过立柱。
- 姿态到位后，小幅度摆动 J6（±5°），若 TCP 位置漂移 >2 mm 说明 J6 轴不竖直或存在偏心 → 重新示教。
- 偏心容差：盖半径 15 mm 下，偏心 1 mm 在 90° 旋转中产生 1.5 mm 侧向位移，夹爪会撬盖。**目标 <1 mm**。

**单段拧**：
- `grasp_once.py` 轻力闭合（effort 1200），接触即停，记录开度 → 盖径。
- 压入 0.6 mm 形成预载，避免起步跳动。
- J6 以 **6°/s** 转（沿用速率铁律），上限 90°（第一段保守）。
- 三个停机判据，任一触发立刻抱持不动：
  1. J6 角度在走、盖子相对瓶身不动（打滑）→ 停，回头改增摩
  2. J6 电流持续 >3 A / 0.3 s → 卡死
  3. 指令-实测 lead > 2° → 臂没跟上

产出：首条 τ-θ 曲线

### S6-4 棘轮续拧（只在 S6-3 转满仍未脱开时启用）

每循环四拍，**每拍都必须验证**：
1. J6 转到段末（+300° 或限位前）
2. 张开夹爪到 **盖径 + 3 mm**，`gripper_angle` 实测确认到位（不能只看指令）
3. J6 回位到起点（+14° 以上，J6 不能进负区）
4. 重新闭合，接触即停（**不用固定目标角度** —— 盖已经转过，齿位变了）

风险：拍 2 若夹爪实际没张开（记忆里踩过"不响应单帧指令"的坑，必须每步重发），拍 3 会硬拧；拍 1 与之前的净推进要扣掉松开后的**回弹**（塑料盖约 5~15°）。

产出：`s6_ratchet_log.csv`（每拍的段末角、累计角、回弹量、脱开标志）

## 4 失败模式与对策

| 现象 | 根因 | 对策 |
| --- | --- | --- |
| 一直转但盖不动（对齐线错开） | 摩擦不足 | 增摩皮、夹竖纹、冲击松动 |
| 电流飙升超 3 A | 螺纹咬死或对轴偏斜 | 立刻停，回退，检查偏心 |
| 盖被撬飞 | J6 轴不竖直、偏心 >2 mm | 重新示教，先做 ±5° 摆动自检 |
| 棘轮回位把盖拧回去 | 张开未生效 | 回位前读 `grip_angle` 实测确认 |
| 脱开瞬间盖子飞出 | 夹持力剩余 + 螺纹弹开 | 脱开判据触发后立即降速并微抬 |
| 全程滑但判据说成功 | 判据用了指令角而非实测 | **判据一律用实测 q6 和实测开度** |

## 5 安全（沿用铁律，不新增例外）

1. 发任何六轴指令前过 `stage2_pose_guard.py`。
2. `q_cmd = q_meas + clamp(Δ, ±rate·dt)`，6°/s。
3. 守卫三道：lead >2°、电流 >3 A / 0.3 s、末端 Z 下降 >150 mm → `_freeze()` 抱持，**绝不失能**。
4. J6 回位前必须实测确认夹爪已张开。
5. 台钳固定瓶子，人不在臂的工作半径内。
6. **断电前物理托住**（实测六轴失能会自由落体）。
