## 配对规则（用错就差分错）

带载段必须配**同姿态**的空载段：

| 带载段后缀 | 配的空载段 |
|---|---|
| `_A` | `M0_A` |
| `_B` | `M0_B` |
| `_C` | `M0_C` |
| `_U1` | `M0_U1` |
| `_U2` / `_U3` | `M0_U2` / `M0_U3` |

**空载基线与物体无关，永久复用**，但必须与带载段同姿态、同 J6（50.6°）、同夹爪开度。
