# 定量实验：电流推算力矩 vs 传感器实测力矩

日期：2026-10-26　|　K6（冻结）= **10.7882 N·m/A**（挂砝码法，r²=0.9958，4.6%）
传感器：VYJN1-5Nm，k = 0.02774 N·m/count
统计口径：每次实验只取 **12 秒** —— 转动开始前 2 s 到开始后 10 s。

---

## 实验一 · 拧紧（`exp1_tighten.html`）

| 指标 | 转动窗（12 s） |
| --- | --- |
| MAE | 0.766 N·m |
| RMSE | 1.006 N·m |
| 偏差（预测−实测） | **−0.013 N·m** |
| 相关 r | 0.696 |
| 预测均值 / 实测均值 | 1.688 / 1.701 N·m（比值 **0.99**） |
| 峰值 | 预测 4.99 / 实测 5.60 N·m |
| 反解 K | **10.84 N·m/A（相对冻结值 +0%）** |

**结论：拧紧段预测与实测高度一致，反解 K 与冻结值仅差 0.5%。**

---

## 实验二 · 松开（`exp2_loosen.html`）

| 指标 | 转动窗（12 s，含弹开冲击） | 稳定松开段（跳过前 4 s） |
| --- | --- | --- |
| MAE | 0.795 | **0.545** |
| RMSE | 1.296 | 0.700 |
| 偏差 | +0.024 | +0.226 |
| 相关 r | 0.426 | ≈0（两路都是近平坦常数） |
| 均值比值 | 0.99 | **0.90** |

**松开有一个拧紧没有的现象：盖子弹开瞬间的冲击尖峰。**

在转动刚开始（约第 1~2 秒）时，传感器瞬间冲到 **−6.99 N·m**（超出 5 N·m 量程），
而臂侧 i6 只到 −2.06 N·m。这是**盖子里储存的扭矩在螺纹脱开的瞬间突然释放**，
是一个瞬态冲击，不是稳态传力。

跳过这个尖峰、只看稳定松开段（臂 t=10~18 s）：
- 预测 −1.98 vs 实测 −2.21 N·m，比值 0.90
- 两者都是近平坦的常数（所以 r≈0 没有意义，但量级吻合）

**结论：松开稳态段量级吻合（0.90），但开头有超出量程的冲击尖峰，需单独剔除。**

---

## 两个实验的对照

| | 实验一 · 拧紧 | 实验二 · 松开 |
| --- | --- | --- |
| 稳态量级 | 吻合（比值 0.99） | 吻合（比值 0.90） |
| 趋势 | 单调上升，r=0.70 | 平坦，r≈0 |
| 峰值 | 4.99 / 5.60（量程内） | −4.09 / −6.99（**超量程**） |
| 异常 | 停住后的弹性弛豫 | 弹开瞬间的冲击尖峰 |
| 反解 K | 10.84（+0%） | 被冲击污染，不可用 |

**共性结论**：
1. **稳态段（真正在传力矩的部分），电流推算力矩与传感器实测吻合到 10% 以内。**
2. **瞬态（拧紧的弛豫、松开的弹开）是额外信号，电流法测不到**——因为那是盖/螺纹里的
   弹性储能释放，不是 J6 电机当前输出的力矩。
3. **K6 = 10.7882 在实验一（干净的单调加载）下被独立复核到 +0.5%。**
