## 2. 没拿到什么（同样重要）

### 三个判据，今天全部被推翻

| # | 判据 | 怎么失败的 |
|---|---|---|
| 1 | I6 **突降** = 盖脱开 | `fast1` 拧开了，I6 末段反而升高 |
| 2 | I6 **末段/首段 < 0.90** = 咬住 | `log1` 比值 0.80 判"咬住"，实际没开 |
| 3 | **逐轮均值下降** = 在松动 | 第 3 组三轮 0.181/0.193/0.177 不降，**却拧开了** |

### 为什么：六类信号逐项排除

用 `3-轮1`（未开）vs `4-轮1`（动了）做对照：

| 信号 | 差多少 | 结论 |
|---|---|---|
| I6 均值 | 0.0103 A（噪声 0.08） | ❌ |
| 夹爪开度 | **峰峰 0.000 µm**（完全冻结） | ❌ |
| dq6 | 0.001 °/s | ❌ |
| 夹爪 effort | 1.2% | ❌ |
| q6 跟踪误差 | 0.007° | ❌ |
| 粘滑峰间隔 | 7.4 vs 7.9 帧（std 4.4/6.0） | ❌ |

**根本原因**：

```
力信息  →  被摩擦上限钳死（τ_max = 2μFr ≈ 1.0~1.5 N·m）
位置信息 → 被位置闭环吃掉（J6 和夹爪都是位置控制）
```

**I6 测的是"J6 出了多大力"，不是"瓶盖转了多少"。** 瓶盖转不转，J6 都顶在同一个摩擦饱和点。

### 什么时候还能看出点东西

**跨轮趋势**：
- 第 3 组（一直没松）：0.181 / 0.193 / 0.177 —— **不变**
- 第 4 组（轮1就开了）：0.171 / **0.124 / 0.122** —— **降 27%**，空转率 60%→83%

⇒ **I6 能判"盖子是否已经脱离"（>20% 变化），判不了"这一轮有没有转"（<6%）。**

## 3. 一路踩的坑

### 夹爪零点两次漂移

| | 物理全开读数 | 推合后读数 | 行程 | 偏移 |
|---|---|---|---|---|
| 中午 | 3.7 mm | −75.88 mm | 79.5 mm | −75.9 |
| 傍晚 | 54.5 mm | −25.13 mm | 79.6 mm | −25.1 |

**编码器和机械都正常，只是零点偏。** 根因推断：**驱动器在上电瞬间把两指当时的位置当成了零点**。

**对策**：
1. 上电前把两指**合到最闭**
2. 上电后自检：全开应读 69.5±0.5、全闭 0±0.5
3. 不对就重标：失能 → 手推合 → **失能标零（0xAE）** → 使能

### 其他五条铁律

1. **拧开 = J6 减小**（正向只会更紧）
2. **先张开夹爪再动 J6**，否则带着盖反向拧紧
3. **TEACHING 模式下指令静默不执行**，表现像"夹爪卡死"
4. `GripperCtrl` 的 effort **必须 `abs()`**，读回是负值
5. `twist` 重发夹爪必须**带压进量**，只发实测值会导致夹持力衰减

### 两个传感器事实

- **夹爪没有电流反馈**，只有 `grippers_angle` / `grippers_effort` / `foc_status`
- **电流精度**：分辨率 1 mA，但噪声 20~80 mA（**90% 是低频漂移**，滑动平均无效）
  - 零偏：J1 = **+0.078 A**（重力矩恒为 0 的轴）
  - J2 噪声 × K = **0.37 N·m**，与 L1 的 J2 OOF 0.305 同量级
    ⇒ **L1 已到电流噪声地板，不是模型不行**

## 4. 要判"开没开"，只剩两条路

**A. 外部测转角**
瓶盖贴标记 / 瓶身画刻度，每轮前后拍照。

**B. 二值上提法**（不需要新硬件）
每轮结束：张开 → J6 不动 → 抬 5 mm → 再夹 → 提 20 mm。
带得走 = 已松脱。
