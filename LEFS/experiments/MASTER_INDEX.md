### 1.2 三份 K 表的关系

| 文件 | 内容 | 用途 |
|---|---|---|
| `calibration/k_table.json` | **主交付**。组约束 K2=K3、K4=K5 | 引用这个 |
| `calibration/k_table_free.json` | 无约束版（J2 4.5364 / J3 3.9419 / J4 0.6841 / J5 0.6263） | 看组约束带来的影响 |
| `calibration/k_table_constrained.json` | 约束版副本 | 存档 |

**为什么要组约束**：无约束时 `c6` 与 K 近似简并，K4/K5 留一偏离 >100%。
约束后 `c6_mm = (−7.22, +7.22, +80.94)`、`bottle_mass_kg = 0.525`、`n_pairs = 10`、`chi2/dof = 17.97/31`。

### 1.3 两种标定方法（不能混）

| 关节 | 方法 | 关键点 |
|---|---|---|
| J2–J5 | **同姿态「空载 − 带载」差分**，静态 | 全量回归（URDF 重力矩 vs 电流）**已判死** |
| **J6** | **正反转差分**，动态 | `ΔI = I_正 − I_反 = 2(τ_摩擦+τ_load)/K6`，摩擦进截距 |

J6 不能用静态法：K6 太大（10.8），0.18 N·m 只需 **0.012 A**，淹没在 0.03 A 噪声里。
动态法实测：L=120 mm、q6 中心 140°、摆幅 ±15°、速率 2°/s，4 点拟合
**斜率 0.1854 A/(N·m)、截距 0.1593 A**，R² 0.9958，摩擦 τ_f ≈ **0.86 N·m**。

**⚠️ 待办**：K6 **没有**并入 `k_table.json`（该文件 J6 仍为 `null`）。引用时两个文件都要看。

## 3. 模型结果

### 3.1 L1 力矩预测（`s4_kfold.py` 5 折 OOF）

| 指标 | 值 | 出处 |
|---|---|---|
| **全 49 段 OOF** | **0.1680 N·m**（折间 std 0.0454） | `S4_KFOLD_REPORT.md` |
| **分布内 46 段（论文主数字）** | **0.1400 N·m** | 同上 |
| 单次 5 段 test | 0.1445~0.1689（**±17%，不可用于比模型**） | `S4_ENSEMBLE_REPORT.md` |
| 逐轴 OOF | J1 0.134 / **J2 0.305** / **J3 0.433** / J4 0.030 / J5 0.072 / J6 0.035 | |
| 边界段 | 0.36~0.40 | |
| 最大离群 | `E2_J3deep` **1.03**（q3=−140°，真分布外，**别删**） | |

**判据**：`τ_m = K·I`（无传感器）。0.05 N·m 目标**不可达**（噪声地板 0.1107，J3 0.305）。
论文 0.018 用厂商标称 K，换算后我们是它的 **2~3 倍**（不是 9 倍）。

**已判死**：全局 EMA 平滑（反升 1.6~2.3%）、少训练、加容量/正则（dq 仅 +3%）。

产物：`runs/kfold/fold0..4.json`、`data/step_kf0..4.npz`、`splits_v2.json`

### 3.2 L2 称重（`s5_weigh.py`）

| 项 | 值 |
|---|---|
| 模型 | `τ_ext = K(I_带 − I_空) = −m(p0 + A3·Φ)` |
| **质心 Φ** | **(+1.5, +1.6, +93.2) mm**，\|Φ\| 93.2 |
| 模型残差 RMS | **0.147 N·m**，条件数 1.4 |
| 单方位可辨识性 | **秩亏**（A3 第三奇异值 = 0），须加"掌心朝上"族 |

| 真实质量 | 平均预测 | 相对误差 | 判定 |
|---|---|---|---|
| 0.1 kg | 0.093 | **23.4%** | 已到噪声地板，不可用 |
| **0.3 kg** | 0.291 | **3.0%** | **可用** |
| 0.5 kg | 0.468~0.476 | 4.7~6.5% | 可用（双方位自解） |

**符号铁律**：单姿态解算 `y = −Δτ`，用 `+Δτ` 会解出负质量。
**求质量优先单姿态**（借固定 Φ）：400 g 单姿态 +0.5~7.5%，双姿态 +27~33%。

与阶段 2 互证：阶段 2 水瓶 `c6 = (−7.2, +7.2, +80.9)`，\|c6\| 81.5 mm，同量级同方向。

### 3.3 FIRST（三步全部落地，2026-10-26）

**第 1 步 分相**：`T_high` 用 **P99.9**（0.58 次/分，recall 66.8%）。P99 误报 6.06 次/分。检测下限 0.2~0.3 kg。

**第 2、3 步 重采样 + 策略训练**（`20261021_stage6/S6_FIRST_REPORT.md`）：
在拧盖 11 段上做 3 臂 × 5 权重 × 5 折 × 2 种子 = 90 次训练，flow matching 无视觉策略。

| 项 | 结果 |
|---|---|
| 相构成 | Free 9.9% / Pre-Contact 8.7% / Contact 81.3%（**接触占多数，与文献前提相反**） |
| 最佳配置 | **FIRST $w_{PC}=5$**：PC **−1.9%**(t=−2.9)、C **−0.7%**(t=−2.4)、Free +5.0% |
| 过采样上界 | $w_{PC}>10$ 收益消失并反转 |
| 加权回归 | 所有权重下 Contact 都**变差**（+0.5% ~ +3.6%，t 最高 +9.3），与文献 D.7 一致 |
| 不可做 | **任务成功率**（无相机/遥操作/闭环环境）；效应仅 1~2%，工程可忽略 |

**分相必须加最小时长**：只用滞回时 J6 的 stick-slip 让接触事件达 78~189 次/段，PC 占 70.9%；
加「接触≥0.3 s、断开≥0.3 s」清理后降到 1~8 次/段。
