   变化量小于 std(0.032)。

## 三、得出的结论

### ✅ 可用（有数据支撑）

1. **K6 = 10.7882 ± 0.4952 N·m/A**（σ/K 4.6%），是厂商系数的 11.26 倍
2. **J6 摩擦 0.86 N·m**，由标定截距反推
3. **可复现配置**：z=179 mm、满力 5000、压进 1.0 mm、15 °/s、棘轮 3 轮 510°
4. **夹爪零点自检流程**（上电前合闭 + 上电后查 69.5/0）
5. **电流精度**：分辨率 1 mA，噪声 20~80 mA，**90% 是低频漂移**（滑动平均无效）
6. **零偏**：J1 = +0.078 A（重力矩恒为 0 的轴），折合 0.092 N·m 虚假力矩
7. **J2 噪声 × K = 0.37 N·m**，与 L1 的 J2 OOF 0.305 同量级
   ⇒ **L1 已到电流噪声地板，不是模型不行**
8. **夹爪没有电流反馈**，只有开度/力矩/FOC 状态位

### ❌ 判死（别再试）

| 方向 | 为什么 |
|---|---|
| 静态法求 K6 | K6 太大，信号埋在噪声里 |
| 全量回归求 K | 早前已判死，本次再确认 |
| I6 突降判"脱开" | `fast1` 开了反而升高 |
| I6 末段比值判"咬住" | `log1` 判咬住却没开 |
| I6 逐轮均值判"松动" | 第 3 组不降却开了 |
| 夹爪开度判"相对运动" | 反馈完全冻结（峰峰 0 µm） |
| dq6 / effort / 跟踪误差 / 峰间隔 | 六类信号逐个测，全部差在噪声内 |
| MIT 恒力矩模式 | 两者阻力都是 τ_max，纯力矩下仍分不开 |

### 🔑 一条物理结论（今天最重要的认知）

```
力信息  →  被摩擦上限钳死（τ_max = 2μFr ≈ 1.0~1.5 N·m）
位置信息 → 被位置闭环吃掉（J6 和夹爪都是位置控制）
```

**I6 测的是"J6 出了多大力"，不是"瓶盖转了多少"。**
瓶盖转不转，J6 都顶在同一个摩擦饱和点——所以这个信息**根本不在电流里**，
换任何统计量都挖不出来。

**信息只存在两个地方**：
- 跨轮趋势（盖子脱离后阻力大幅下降，>20%）
- 外部测量的转角
