## 1 一句话结论

**从「PC ↔ CAN ↔ 臂」的时序同步，一路验到「用关节电流给物体称重」，并且每一段都留了可复算的判据。**

三个真正站得住的结论：

1. **信号链是干净的**：3138 帧/s、六路 200 Hz、并发 75 s 录制 + 下发零丢包，`q_cmd` 与 `q` 的时间对齐有实测滞后；
2. **力矩尺度可以标定，但只能标相对量**：`ΔI = τ_pay/K + δ` 的差分口径成立，`K` 与 SDK 内部系数差 4 倍（大关节）/ 0.78 倍（腕关节）；
3. **无传感器也能称重**：`τ_ext = K(I_带载 − I_空载) = −m(p0 + A3·Φ)`，静止平均 12 s 后分辨率 6~10 g；但**单一方位数学上无解**，必须两个方位族。

## 3 阶段 1（L0）：信号链与同步

### 3.1 L0-a 被动采集（660 s）

| 判据 | 要求 | 实测 |
| --- | --- | --- |
| 帧率 | 200 Hz（5.0 ms） | 2 073 061 帧 / 660.2 s = **3138 帧/s**，六路各 **199.94 Hz** |
| 空洞 | 无 >100 ms | **0 个** |
| 六路齐备 | ≥99% | 各 132 000 / 132 000 |

**顺带定案 `R12`**：`0x251` 位置字段 / `0x2A5` 角度字段 = **999.893**（rad 口径）/ **0.998**（mrad 口径），两条独立路径互为倒数 ⇒ **`0x251` 单位 = 0.001 rad**；`q` 只取 `0x2A5~0x2A7`。

### 3.2 L0-b 主动下发

| 档 | 条件 | 结果 |
| --- | --- | --- |
| 单轴 | J6 ±3° 正弦 | 跟随，响应比 **0.8672**，滞后 **60.0 ms** → `R19` 关闭 |
| **六轴** | 同相 ±2° @ 0.1 Hz / 60 s | **六轴全部跟随**，响应比 `0.9391 / 0.9403 / 0.9409 / 0.9420 / 0.9416 / 0.9407`，滞后 J1~J3 80 ms、J4~J6 60 ms |

三条读法：

- 六轴响应比**离散度仅 0.3%** ⇒ 系统性约 −6% 衰减，不是某一轴的问题；单轴那次 0.8672 与六轴 0.9407 不同，**0.87 不能当基线**；
- 滞后 60/80 ms 全是 20 ms（50 Hz 重采样栅格）的整数倍 ⇒ **量化假象，不是真实分辨率**，L1 对齐必须亚采样插值；
- **`R30` 被证伪**：并发「75 s 录制 + 18 029 帧下发」中，`RX/TX` 的 `dropped / overrun / errors / carrier` **前后全为 0**，六路捕获率 99.89%。audit 更进一步：8 个 10 s 桶里 **7 个 `hs` 严格 = 12 000**（6 轴 × 200 Hz × 10 s）。⇒ **双进程采集不是断流元凶**，阶段 3 无需改单进程架构。

## 4 阶段 2：力矩尺度核验（K 标定）

### 4.1 口径：同姿态「空载 − 带载」差分

```
ΔI_j = τ_pay,j(c6)/K_j + δ_j
```

只解**相对力矩**，不碰 URDF 质量。由 `s21_group_fit.py` 输出 `calibration/k_table.json`（10 对姿态、0.525 kg 水瓶、χ²/dof = 17.97/31）。

| 轴 | K (N·m/A) | 状态 | K / SDK | 留一法偏离 |
| --- | --- | --- | --- | --- |
| J1 | — | **未标定** | — | 重力 ∥ 轴 ⇒ τ₁ ≡ 0，需滑轮切向拉 |
| J2 | **4.7185** | 已标定 | **4.00×** | 11.8% |
| J3 | **4.7185** | 已标定（组约束） | 4.00× | 11.8% |
| J4 | **0.7446** | 弱约束 | 0.78× | **79.6%** |
| J5 | **0.7446** | 弱约束 | 0.78× | 79.6% |
| J6 | — | **未标定** | — | τ₆ 跨度仅 0.054 N·m，σ_K/K = 21% |

**载荷质心 `c6 = (−7.2, +7.2, +80.9) mm`**（沿轴 81 mm / 横向各 7 mm）——这就是「水瓶斜着拿」的定量答案。

### 4.2 三条必须记住的判据经验

1. **判据用留一法，不信解析 σ**：解析给 2.8%，留一偏离 107%。根因是 `c6` 与 `K` 简并；
2. **加组约束是有代价的交换**：`K2=K3 / K4=K5` 换来 `c6` 可辨识，Δχ² 仅 +0.81；
3. **全量回归（URDF 重力矩 vs 电流）已判死**：带载 4 点 J2/J3/J5 相关性全反号、χ²/dof = 1204 ⇒ **URDF 质量与实机不符**，不能用它算绝对重力矩。

### 4.3 缺口（论文必须写明）

- 指南 §5.2 第 4 步「卸载重测回差」**未做**（带载轮与空载轮相隔数小时且中间断电，不是严格回差）；
- J4/J5 弱约束：唯一负向激励点 K3 缺失即退化；
- J1/J6 **结构性未标定**：J1 需滑轮 + 测力计切向拉，J6 需偏心横杆 80 mm（τ₆ 要放大 ~16 倍）。

## 7 阶段 5（L2）：用电流称重

### 7.1 口径

```
τ_ext = K(I_带载 − I_空载) = −m · ( p0(q) + A3(q)·Φ )
```

「空载基线」= **同一姿态、同一 J6、同一夹爪开度**下的空载段逐姿态做差 —— 这一步把 L1 模型的系统偏置**完全消掉**（`weigh_arm.py` 因此不需要加载 L1 模型）。

### 7.2 三个硬结论

1. **单一方位数学上无解**：仅「夹爪朝前」时 `A3` 第三奇异值恰为 **0**（零空间 = 重力在 link6 系方向，因 `τ = Φ × F` 对沿 F 的平移不变）⇒ **单一方位定不出质心**；加「掌心朝上」族（工具轴竖直，F 变 `(0,0,−1)`）后才满秩，条件数 **1.4**。做类似标定别再省这一步。
2. **质心 `Φ = (+1.5, +1.6, +93.2) mm`（|Φ| = 93.2 mm）**，残差 RMS **0.147 N·m**；与阶段 2 水瓶 `(−7.2, +7.2, +80.9)` 同量级同方向 —— **两条独立链路互证**。
3. **线性度 `R²` 中位 0.989**（J2/J3/J5）；**J4 基本看不到载荷**（斜率 0.02）——载荷几乎通过 J4 轴线，与分析一致。

### 7.3 验收

| 项 | 结果 |
| --- | --- |
| 留出 0.3 kg 盲测 | **3.0%**（A +0.1% / B −1.6% / C −7.4%） |
| 留出姿态 A/B/C | 2.6% / 5.7% / 2.1% |
| 留出 0.1 kg 盲测 | **23.4%** —— 已在噪声地板，不可用 |
| **换新物体、完全免标定** | 把未知量换成 `(m, Ψ=mΦ)`，「朝前 + 掌心朝上」两段即满秩（cond 7.0）：A+U1 两段 2 分钟 → `0.468 kg`（**−6.5%**）；A+C+U1 → `0.476 kg`（**−4.7%**） |
| 重复性 | **1~2%**（σ_m/m 形式不确定度 0.9~2.0%；OBJ1 vs 195135 差 3 g = 0.4σ） |
| 最小可分辨 | 单帧 0.14~0.26 kg；静止平均 12 s 后 **6~10 g** |

### 7.4 不能宣称的（写论文时要避开）

- 单段秩亏（仅 A 一段 → 0.604 kg，+20.8%）；
- **`m` 与 `Φ` 同时解会把质心位置误差泄漏到质量上**（Δτ 只差 3% 可致质量差 15%）⇒ 重复称同一物体**必须保持夹持位置一致**；
- 0.1 kg 档不可用；
- 标定件：33 段数据 = 阶段 5 标定 18 段（M0~M3）+ 新物体 8 段 + 阶段 4 补采 7 段；清单见 `S5_DATASET.md`、逐档误差见 `S5_WEIGH_TABLE.md`。

1. 发六轴指令前必须过几何闸门 —— 力矩可辨识 ≠ 几何安全（事故 P4：TCP z 仅 67 mm、净空 −28 mm，夹爪弯进底盘立柱）；
2. 指令跟实测走（`q_cmd = q_meas + clamp(Δ, ±rate·dt)`），速率默认 6 °/s，绝不按时间推进；
3. 守卫三道：卡死窗口（带 `lead > 2°` 滞后）、电流 >3 A / 0.3 s、末端 Z 降 >150 mm；触发后 `_freeze()` 重发实测姿态抱住，**绝不失能**；
4. **断电前必须物理托住** —— URDF 净空不能作为「可以放手」的依据（实测断电六轴全失能自由落体：J2 60→34.9、J5 40→25.7）。

## 9 方法论：五次「差点判错」都变成了判据

| 事件 | 错误形式 | 长出来的规则 |
| --- | --- | --- |
| 门 8 连续失败 | VM 上跑的是旧脚本 | 上传后先 `sha256sum` + `--version` 双关对账，对不上不许跑 |
| 「丢 42% 帧」 | 分母用墙钟，实际是 52 s 后断流 | 频率一律用**帧时间跨度**算，不用墙钟 |
| `--to-can-ctrl` 显示全绿 | 少了 `--allow-write`，一帧没发 | 「成功的那部分会掩盖没做的部分」→ 未发送必须显式报错 |
| `0x2A8` 零帧 | 差点判「夹爪坏了」，实际是整条 netdev 失效 | 判据必须带对照通道，否则结论指向错误对象 |
| `ip link set can0 up type can ...` 报 `No such device` | 文案把人引向 USB 直通 | can0 拉起一律三步法：down → `type can bitrate` → up |

另外三条数值纪律：

- **伪精确比空白更危险**（指南 §2.3）：没有实测就写 `null` + 「未实测」，官方标称单独登记；
- **判据用留一法，不信解析 σ**（阶段 2 的 σ 报 2.8%、实际偏离 107%）；
- **同型错误会重复三次**（R18 / R27 / R31 / R33 都是「无返回值或默认值被当成真实结果」），所以工具一律自建 socket 逐帧判成败 + 自测用例固化。
