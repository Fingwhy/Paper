## 一句话总结

FACTR 2 用「学出来的外部关节力矩」替代昂贵的力/力矩传感器：NEXT 只需 10 分钟自由运动数据、1 分钟训练，就能让没有力矩传感器的机械臂获得接近专用传感器的外力估计；再用该信号把示教轨迹切成自由运动 / 接触前 / 接触三段并按相位重采样（FIRST），在 5 个长时序接触任务上把任务进度相对此前最强的力感知策略再提升约 17 个百分点。

## 三条核心贡献

1. **数据驱动的无力传感器外部力矩估计（NEXT）**：无需专用力传感器、无需机器人专属系统辨识，只训练一个循环网络，估计质量超过此前方法。
2. **低成本机械臂上的力反馈遥操作**：把估计出的力信号接入双边遥操作，使 Piper、YAM 等无传感器平台获得与带传感器系统相当的反馈质量。
3. **力信息驱动的重采样训练（FIRST）**：用力矩估计识别示教中的接触前与接触阶段，在行为克隆时提高这些样本的采样概率。

## 背景

接触富操作（插装、拧紧、柔性物体）需要力觉，但六维力传感器只出现在 Franka、Flexiv、KUKA 等高价平台。Piper 整机约 2,500 美元，Franka 约 30,000 美元，给末端加装力传感器的成本有时超过机械臂本身。传统压阻式传感器需精密加工弹性体 + 多组应变片；电容式（CoinFT）与磁性皮肤（ReSkin）便宜但力度量不足。

既有「无力传感器」路线的瓶颈：解析建模 + 系统辨识需要大量人工，且残差中混入非线性摩擦、静摩擦、背隙、迟滞、温漂、噪声、力矩纹波、死区与饱和等历史相关效应；自编码器异常检测只能判断「有没有碰撞」；监督式方法需要额外标注接触数据。

## 方法

### NEXT：神经外部力矩估计

核心恒等式：

```
τ_ext = τ_m − τ_f
τ_f   = M(q)q̈ + C(q,q̇)q̇ + g(q) + τ_other
```

用网络直接学 τ_f：

```
τ_f = f_θ(x),   τ_ext = τ_m − f_θ(x)
x_i = [ q_{i−H:i},  q̇_{i−H:i},  Δq_{d,i−H:i} ]
L(θ) = (1/N) Σ ‖ f_θ(x_i) − τ_{m,i} ‖²
```

- 数据：10 分钟无接触自由运动轨迹（单关节全行程 → 多关节类笛卡尔 → 快慢速重复）。无接触时 τ_m 即自由空间力矩，可直接作监督标签。
- 结构：2 层 LSTM（隐层 128）+ 2 层 MLP（隐层 256），dropout 0.1，H = 50，AdamW，学习率 1e-3，权重衰减 1e-6，梯度裁剪 1.0，早停（patience 20）。
- 训练：单张 RTX 3090 约 1 分钟；数据 100 Hz。
- 部署：无状态滑窗（每条序列重置隐藏状态），滚动缓冲区；单核 CPU 1.76 ms/次 ≈ 568 Hz，实际以 100 Hz 运行。

### FIRST：力信息驱动的重采样训练

1. 接触分数 f_t = ‖τ_ext,t‖₁，用双阈值滞回（T_high / T_low）得到二值接触指示 c_t。
2. 接触起点 T_onset = { t | c_{t−1}=0, c_t=1 }。
3. 相位标签：接触（c_t=1）；接触前（接触起点前 F 个控制周期，即 1 秒）；其余为自由空间。
4. 训练时按相位权重 w_F : w_PC : w_C 做加权随机采样，p_t = w(s_t)/Σ w(s_j)。**只改采样分布，不改损失。**

策略设定：观测 o_t =（M 路图像, q_t, τ_ext,t），输出长度 30 的动作块，flow matching 速度场目标训练。

## 实验与结果

### 外部力矩估计（Franka，L1 误差 Nm）

|---|---|---|

| 接触 | FILIC | 4.395 ± 1.531 |
| 接触 | 扰动观测器（DO） | 1.471 ± 0.761 |
| 接触 | **NEXT** | **0.547 ± 0.348** |
| 自由空间 | FILIC | 2.460 ± 1.358 |
| 自由空间 | 扰动观测器（DO） | 2.429 ± 1.298 |
| 自由空间 | 外部传感器（Franka 自带） | 0.449 ± 0.208 |
| 自由空间 | **NEXT** | **0.414 ± 0.278** |

- 接触段比 FILIC 低 87.6%，比 DO 低 62.8%。
- 自由空间甚至优于 Franka 自带传感器（更平滑、更贴近零）。

### 力反馈遥操作（Franka，20 人用户研究）

五种条件：无反馈 / DO / 主从位置-位置（PP）/ FACTR Teleop（Franka 传感器）/ FACTR Teleop + NEXT。反馈律 τ_feedback = K_{f,p}·τ_ext。NEXT 易用性更高、所需关节力矩更低，与使用专用传感器的 FACTR Teleop 相当；Piper 上重复实验同样优于基线。

- 只上采样接触前（PC）最好；只上采样接触（C）几乎无效。

### 其余三组对照

- **相位级验证损失**：默认采样下接触前/接触段的损失高于自由运动段；上采样后两者被拉低。
- **上采样倍数**：m ≈ 5 最佳，更大饱和或退化；逐任务配比多为 1:5:1，拧瓶盖为 1:3:3。
- **无力矩输入也能用**：仅用 NEXT 离线切相位重采样，ACT 在皮带装配从 0.220 → 0.360（PC）；同时喂入力矩最好。
- **原始电流 vs 学到的力矩**：NIST 插装 0.220 → +电流 0.431 → +τ_ext 0.567；拧瓶盖 0.440 → 0.440 → 0.525。用电流的策略常「拧过头」。
- **改损失 vs 改采样**：加权回归无效甚至更差（0.345 < 0.453），重采样稳定有效（0.573）。

## 关键结论

1. 残差法的瓶颈在未建模效应，网络一次性学掉它们。
2. 时序上下文是必需品（MLP 弱于循环网络；H 从 10 到 50 持续改善；Δq_d 提供执行器努力线索）。
3. 「估计」与「使用」应当解耦：长历史留在专用模块，只交出压缩后的接触量。
4. 数据分布比网络结构更值得动刀（不改损失，改采样，+17 pt）。
5. 经验法则：接触前样本比接触中样本更值钱（4/5 任务支持）。

## 局限

- 绝对力矩尺度依赖力矩常数 K，K 不准时需对外部力传感器标定。
- 机型专属，跨机械臂可能需重训。
- 接触检测依赖双阈值（T_high / T_low），需按机型标定。
- 估计的是关节空间力矩，非末端六维力；末端阻抗控制需雅可比映射。
- 任务进度指标依赖人工划分阶段（拧瓶盖按「过拧次数」扣分），跨任务不完全可比。

## 复现要点

1. **信号链**：读出各关节电机电流与力矩常数 K；100 Hz 采 q、q̇、q_d；先在自由空间验收残差是否贴零。
2. **数据**：10 分钟覆盖式自由运动，可录制一次在新机上回放。
3. **训练**：小网络 + 早停，3090 约 1 分钟。
4. **FIRST**：先 1:5:1 跑通，持续接触型任务再试 1:3:3；只改采样器，权重用 WeightedRandomSampler 实现。
5. **坑**：K 不准导致整体缩放；自由空间数据混入轻微接触会污染标签；Piper 无力矩真值需替代标定。
