# PiPER 标准版 FACTR 2 复现实施报告

> 修订版 2.0　2026 年 10 月 19 日
> 论文依据 FACTR 2 Learning External Force Sensing for Commodity Robot Arms Improves Policy Learning，arXiv 2606.12406v2。
> 面向准备使用 PiPER 标准版开展 NEXT 外部关节力矩估计与 FIRST 策略学习实验的研究人员。

## 摘要

FACTR 2 的复现应分别回答四个问题：能否准确预测无接触时的关节力矩，预测残差能否识别真实接触，残差是否具有可信的物理力矩尺度，以及使用该信号的 FIRST 重采样能否改善策略表现。四项结论需要不同证据，不能由一个自由空间误差数字替代。

本报告覆盖版本固定、信号采集、尺度核验、NEXT 训练、接触验证、FIRST 标注、策略对照和可选力反馈实验。论文事实以 [P1] 标注，官方代码与设备资料以 [C1]、[S1] 等标注；自行提出的起始值明确称为“工程建议”，不作为论文标准或厂家保证。

推荐先完成单臂的信号链、自由空间预测和受控接触验证，再决定策略训练投入。力反馈遥操作是独立分支，不是 FIRST 的前置条件。当前项目保存的是资料、报告与文档生成脚本，本报告不宣称已经完成实机训练或性能验收。机械臂数量、固件、末端、相机和算力应在开工前盘点。

## 阅读导航

第 1 至 3 章介绍研究结论、方法和版本；第 4 至 8 章完成信号链、标定、数据、NEXT 和接触验证；第 9 至 11 章完成 FIRST、策略对照和可选力反馈；第 12 至 14 章规定交付、故障排查与资源计划。附录给出数据契约、离线代码、结果模板与来源索引。

## 1 复现目标与证据边界

### 1.1 研究解决的问题

无专用关节力矩传感器的机械臂通常只能获得位置、速度和电机电流。用解析动力学扣除自身运动力矩时，摩擦、迟滞、温漂、传动误差和建模偏差会进入残差。NEXT 使用自由运动数据学习自由空间力矩，再从实测力矩中减去预测，获得外部关节力矩估计。FIRST 利用该估计标记接触相关阶段，改变训练样本抽样概率而保持行为克隆损失不变。[P1，第 3 至 5 节]

“无专用力传感器”不等于无需核验力矩尺度。电流换算、时间同步、末端负载与控制模式均会影响标签。外部关节力矩也不等于末端六维力；从关节力矩反推末端力还需要接触位置、运动学和可辨识性条件。

### 1.2 三种复现口径

| 口径 | 需保持或记录的条件 | 可以支持的结论 |
| --- | --- | --- |
| 论文设定复现 | 数据频率、模型、任务及评价协议尽量一致 | 在限定条件下比较论文数字 |
| PiPER 工程适配 | 记录频率、固件、末端和实现差异 | 证明当前设备配置的有效性 |
| 最小趋势验证 | 单臂、较少示教、简化任务或策略 | 检验机制趋势，不等同五任务结果 |

同为 Piper 只能说明平台相关，不能确认硬件与控制链完全相同。实际型号、固件、安装方向、负载、SDK 和实测频率均需归档。改变这些条件后，应重新检查模型适用范围。

### 1.4 自由空间结果的解释边界

恒输出零外力的系统在零外力测试中也能获得零误差。因此，自由空间结果证明的是该运动分布下的预测和残差表现，不能单独证明接触有效性。必须补充独立接触事件，并在报告绝对精度时加入外部参考。

缩小电流至力矩的换算系数，也可能缩小以 N·m 表示的预测误差。自由空间误差低不能反过来证明 K 正确。报告结论应分别写为“自由空间建模通过”“接触检测有效”“绝对尺度有效”和“策略收益获得支持”。

## 2 NEXT 与 FIRST 的实现定义

### 2.1 变量与力矩约定

q 是实测位置，dq 是实测速度，q_cmd 是当前控制周期对应的参考位置。位置统一为 rad，速度为 rad/s，电流为 A，力矩为 N·m。按论文约定：

```text
delta_q = q_cmd - q
tau_measured = K * current
tau_free_hat = model(history(q, dq, delta_q))
tau_external_hat = tau_measured - tau_free_hat
```

工程中的 K 指有效电流至关节输出力矩换算系数，需明确是否包含减速比、效率和符号。不可把电机轴常数直接当作关节侧常数。若驱动定义与论文正方向不同，应在数据入口统一转换并通过已知方向载荷核验，不能在后处理任意翻转以改善指标。

自由运动时以 tau_measured 为监督标签，优化自由力矩预测 MSE。模型预测窗口末端的当前力矩，不是未来力矩。变更末端或负载后，需重新检查或训练模型。

| 项目 | 论文设定或核验结果 |
| --- | --- |
| 输入 | q、dq、q_cmd 减 q 的时间历史 |
| LSTM | 2 层，隐藏宽度 128 |
| 预测头 | 2 层 MLP，隐藏宽度 256 |
| Dropout | 0.1 |
| 优化器 | AdamW，lr=0.001，weight decay=0.000001 |
| 损失与梯度 | MSE，梯度范数裁剪 1.0 |
| 早停 | patience=20，warmup=10，min delta=0.00001 |
| 论文时间设置 | 100 Hz，H=50，约 0.5 秒历史 |
| 50 Hz 适配 | H=25，约 0.5 秒历史，属于工程改造 |
| 隐状态 | 每个窗口重置，不跨窗口累计 |

论文超参来自 [P1，表 3、表 4]。作者公开代码的两层预测头为 Linear、ReLU、Dropout、Linear；旧稿三个 Linear 与 GELU 的示例不再作为对应实现。[C2] 应锁定代码 commit，并保存最终配置，不能只抄论文表格而忽略实现默认值。

H/fs 为名义窗口时长，首末采样点间隔是 (H−1)/fs。FIRST 的接触前窗口另取 1 秒。50 Hz 适配即使历史时长相同，也不与 100 Hz 数据完全等价。论文约 1 分钟训练和 1.76 ms 单次 CPU 推理仅对应其软硬件条件，实际耗时需另测。

### 2.3 评估 MAE 与接触打分

```text
MAE = sum(abs(predicted - reference)) / (N * J)
MAE_per_joint[j] = mean(abs(predicted[:, j] - reference[:, j]))
contact_score[t] = sum(abs(tau_external_hat[t, :]))
```

单臂 J=6。评估误差对关节平均，接触打分对关节求和，两者不能混用。六关节求和误差不能直接与论文 0.018 N·m 比较。所有误差在反归一化后的物理单位中报告，附逐关节偏置、分位数和测试时长。

### 2.4 FIRST 标签与权重

接触打分采用 L1 范数。大于等于 T_high 进入接触，小于等于 T_low 退出，中间保持原状态。接触样本标为 C；每次接触起点前 1 秒内的非接触样本标为 PC；其余为 FS。C 优先，轨迹间重置状态，不跨 episode 构造 PC。

采样概率与阶段权重成比例。论文多数任务使用 FS:PC:C=1:5:1，拧瓶盖使用 1:3:3，这是任务相关的结果，不保证新任务最优。[P1，附录 D.3] 固定训练步数、抽样总量与损失，才能比较重采样机制。

| 机械臂 | 型号、数量、设备编号、固件、实际限位 |
| 负载 | 夹爪或手、相机、支架、传感器、线缆及安装姿态 |

| 主机 | 系统、CPU、GPU、驱动、Python 与框架版本 |

存档标准版规格包括 1.5 kg 额定负载、约 626.75 mm 臂展和 ±0.1 mm 重复定位精度。[H1、H2] 全部末端附加物都应纳入负载预算，并核对姿态与动态限制。重复定位精度不能证明插装任务没有视觉、标定或柔顺性瓶颈。

不假定用户已经拥有机械臂或 GPU。单臂 NEXT、双臂策略、带力反馈主臂是不同配置，应分开预算。原厂主从联动不自动等于论文完整力反馈系统。

作者已公开 NEXT 实现，提供采集、训练、在线推理和可选遥操作模块。[C1] 先用官方链路建立基线，再记录自写实现、降频或硬件适配的差异；不能据此认为 FIRST 的全部数据和策略实验已在本项目具备。

```bash

```

首次选定版本后记录实际 commit，后续实验恢复同一版本；SDK、URDF 和策略框架也单独锁定。查询日期不是代码版本号。

本次核验的作者说明使用 ROS2 Jazzy 与 Python 3.12 开发测试，硬件示例还列出特定 piper-sdk 依赖。[C1] 不应将该环境与旧稿其他 Ubuntu 或 SDK 组合混称为已验证配置。固件需要不同协议时，先核验兼容性，再选软件版本。

### 3.3 实验环境与资料环境分离

当前 Windows 虚拟环境用于资料处理，不是已验证的机器人实验环境。机器人实验另建环境并锁定 CAN、ROS2、PyTorch 等依赖。先完成导入和帮助命令检查，再启动依赖实际话题的节点；“程序启动成功”不等于 L0 通过。

厂家 V2 与 V3 在 MIT 模式编码及力矩字段等方面有差异。[S1] 必须同时核对固件、解析器、消息类型和控制参数。URDF 与运动学偏置需按设备版本核验，保存来源与哈希。

### 3.4 电流符号与系数的未决项

厂家高速反馈类注释与解析代码对电流有符号性的表达存在差异。[S2、S3] 实施前保存正反方向运动与受控加载的原始帧，对照解析结果和物理方向，不能仅凭 uint16 注释推断负力矩不可测或自行修改解码。SDK 的 effort 系数可作核验起点，不是本机校准证书。

## 4 L0 信号链与同步

### 4.1 分层保存数据

底层保存 CAN ID、原始字节、接收时间和异常；解析层保存每个关节的数值与更新时间；样本层在统一时轴上构建 q、dq、q_cmd、current 和 tau_measured。原始层只追加，不被重采样覆盖。

存档协议将高速反馈 0x251 至 0x256 标为 20 ms，即名义 50 Hz。[H3] 必须对当前固件逐 ID 实测。50 Hz getter 调用只能证明轮询频率，不能证明收到 50 Hz 新数据；各关节缓存可能有不同年龄。

### 4.2 单位与指令语义

| 字段 | 保存单位 | 入口检查 |
| --- | --- | --- |
| q | rad | 0.001 度整数换为度后再转 rad |
| dq | rad/s | 确认关节侧或电机侧定义 |
| q_cmd | rad | 当前执行参考及其有效时间 |
| current | A | 原始比例、符号与饱和范围 |
| tau_measured | N·m | K 与方向明确后生成 |
| 时间 | s 或 ns | 时钟类型、起点与设备偏移 |

不能用 q 代替 q_cmd，否则跟踪误差恒为零。若只下发稀疏终点而控制器内部插值，终点不一定等于实时参考，需先核验指令接口。缺少 q_cmd 时，停止完整输入训练，或另立不含跟踪误差的消融实验；测量位置的一阶保持不能重建指令。

### 4.3 因果对齐与数据新鲜度

保留每种信号的源时间戳，以已到达观测进行对齐。逐样本计算关节间时间跨度、各字段年龄及是否重复。50 Hz 适配的初始工程建议是将超过一个目标周期的关键反馈标为过期，并尽量将跨关节跨度控制在半个周期以内；若实测发送结构不满足，应修改并冻结判据或降低频率，报告代价。

离线线性插值可能使用未来观测，导致离线成绩与在线部署不一致。如采用这种分析，应单列结果。升到 100 Hz 不增加电流真实带宽。相机也需要时钟偏移与漂移校准，并把视觉与模型延迟计入总链路。

### 4.4 首帧与异常退出

有效首帧要求全部必需 ID 已到达、时间戳有效、字段通过范围检查。真实零位可以全零，不能以“角度不全零”判断有效。异常至少覆盖 NaN、缺帧、过期、饱和、错误状态、保护触发和指令中断。

记录按段落盘，异常退出仍保留已完成段。停止时按控制栈验证过的流程先停运动，再安排支撑、保持或失能。不能假定无条件 DisableArm 在任何姿态都安全；重力下断力的行为需要检查。异常数据带标记保存，不静默填零进入训练。

### 4.5 验收输出

连续采集至少 10 分钟静止与低速安全运动，输出逐 ID 周期中位数、P95/P99、最大间隔、超时次数、总线错误和样本有效率。目标频率、循环频率与有效新样本率分别报告。

无帧序号时，不能仅由平均频率证明“零丢帧”。更准确的表述是“未发现超过某判据的间隔异常”，并公布判据。L0 通过要求单位、方向、指令语义可解释，同步满足冻结标准，故障不会静默污染训练数据。

## 5 力矩尺度与独立参考

### 5.1 标定的目的

SDK 已提供分组 effort 系数，但需要核对其输入输出单位及目标固件适用性。[S2] 接触趋势实验可使用明确说明的相对尺度；报告绝对 N·m 误差时，需要厂家可追溯解释或独立尺度验证。不能仅凭残差贴零确认 K。

### 5.2 静态加载差分

固定受控姿态，比较已知外部载荷施加前后的稳态电流。已知外力和力矩先转换到统一坐标系，再通过接触点雅可比映射到关节：

```text
delta_tau_reference = transpose(J_contact(q)) @ wrench
delta_tau_reference[j] ~= K[j] * delta_current[j]
```

符号按物理方向与本文残差定义统一。砝码法需要质量、重力方向、施力点和力臂；力传感器需要零点、量程、坐标变换和同步。不能把参考传感器的 N 值直接与关节 N·m 相减。

采集多姿态、多载荷、正反加载和卸载循环，记录稳态时间、温度与回差。拟合检查截距和残差；差分只能消除部分本体重力，不能自动消除摩擦或姿态偏移。小电流差导致比例不稳定，避免逐点相除后简单平均。

### 5.3 可辨识性与验收

各关节必须获得足够的独立激励。竖直轴可能无法由竖直重力配重有效激励，需改变施力方向或参考装置。未激励关节标为未标定，不借用其他关节系数声称全臂已通过。

输出每关节 K、方向、标定区间、独立验证误差、回差与参考不确定度。以是否满足预设实验精度验收，不强制未经论证的 5% 离散度或六关节 K 相近。标定与最终接触测试分开，尺度不确定度进入结果解释。

### 5.4 不以 MIT 命令充当真值

T_ref 是控制输入，实际输出还受反馈项、重力、摩擦、限幅和内部换算影响。T_ref/current 可能只验证了驱动预设比例，不能独立证明实际力矩准确。本版删除该方法作为主标定路线；MIT 控制研究应另立实验并使用外部参考。

### 5.5 负载和接口

安装传感器改变了重力与惯性，应在最终固定末端配置下采集自由空间模型；更换末端后重新验收。外部传感器接线遵守目标机型接口限制，不能因接头带 CAN 就假定允许任意设备接入。[H2] 选择独立兼容接口，并核算重量、电源和线缆牵引。

## 6 自由运动数据集

### 6.1 采集计划

论文使用约 10 分钟自由运动，覆盖单关节、多关节联动及不同速度。[P1，附录 A.3] 建议额外采验证与独立测试轨迹；10 分钟总量再按 8:1:1 切分，与 10 分钟训练数据不是同一预算。

先在保守空间验证轨迹、自碰撞余量、速度、加速度和停止功能，再逐级扩展到预期工作范围。不要求机械全行程，也不默认 100% 速度。保护触发段单独记录，不能通过降低保护等级掩盖过激轨迹。

按独立 episode 采单关节低速、不同速度、多关节运动、重复路径和静止保持。保存轨迹参数、负载、温度与异常。人工直接拖动会施加外力，不能未经验证就作为自由空间标签；可先记录轨迹，再在无人工接触时回放。

### 6.2 覆盖与质量检查

![图 2　论文的自由运动数据覆盖示例；本地应检查六关节的位置、速度、跟踪误差与力矩分布（论文图 8）](paper/figures/doc/fig08_dataset_coverage.jpg)

逐关节绘制位置、速度、跟踪误差、电流和力矩分布，并检查时间曲线、方向切换和重复性。直方图相似不能证明动态历史充分。尖峰可能来自通信、保护或接触，先追溯原因，不一律平滑删除。

预热以漂移稳定性为依据，记录温度和静态电流变化。固定 5 分钟仅可作起点，不保证热稳态。设置同温度测试和额外冷暖机测试，以区分基本复现与鲁棒性。

### 6.3 切分与窗口

先按完整 episode 或采集批次划分训练、验证、测试，再构建窗口；禁止跨段和跨集合。标准化仅在训练集拟合。若只能切一段连续录制，边界至少隔离完整历史窗口，并说明轨迹相关性仍存在。近似重复的轨迹按录制组隔离。

同分布独立测试用于对照基本性能；未见速度、姿态或温度作为额外外推测试。不能只用外推测试误差判断论文是否成立。保存切分清单，测试集不参与模型或阈值选择。

## 7 L1 NEXT 训练与验证

### 7.1 先建立可复查的训练闭环

以官方锁定版本为起点，确认输入键、历史长度、标签单位、归一化与网络。先用小数据完成训练、保存、重载和离线预测，再开始完整实验。第一次排障不要同时改频率、输入、结构与滤波。[C1]

权重需与配置、标准化统计、数据和切分清单共同保存。仅一个模型文件不足以复现。batch、最大 epoch 等论文未明确或本地改变的项标为工程选择，记录最终解析值而非仅保存模板。

### 7.2 训练步骤

1. 核验字段、单位、同步与有效掩码，排除接触污染和故障段。
2. 按冻结切分生成因果窗口，标签取窗口最后时刻。
3. 只从训练集拟合归一化，验证与部署复用同一参数。
4. 按第 2 章模型与优化设置训练，记录种子和早停细节。
5. 用验证集选择 checkpoint，最终测试仅评估一次既定方案。
6. 若输出标准化，先反变换再计算物理残差和指标。

### 7.3 自由空间验收

可将独立同分布测试关节平均 MAE≤0.05 N·m 作为初期工程目标，但它不是论文标准，更不能证明 K 准确。同时报告逐关节 MAE、偏置、P95/P99，静止与运动、速度档和温度分项，以及有效样本数与时长。

残差均值接近零可能只是正负抵消，不能替代绝对误差。结论限定为“在某设备配置和测试分布下，预测误差为某值”。与 0.018 比较前，先确认平均方式、物理尺度、频率和测试条件。

### 7.4 基线与消融

FILIC 使用逆动力学残差，动量扰动观测器避免直接依赖加速度；论文 Piper 基线动力学来自厂家 URDF。[P1，附录 A.4] 本地必须让基线与 NEXT 使用相同测量、负载、同步和测试集，记录微分滤波、观测器增益与初始化。模型配置错误的基线不能证明 NEXT 的真实优势。

建议补充简单回归或均值基线，重训比较 H=1、无速度和无跟踪误差输入。推理时将速度置零仅是敏感性诊断，不是泄漏检查。历史变短后性能不降，应结合统计波动和任务分布分析，不直接断言数据多样性不足。

## 8 L2 接触验证

### 8.1 检测与力矩精度分开

没有外部参考时可以报告接触检出和延迟，不能宣称复现 Franka 0.547 N·m 的接触精度。Piper 无内置参考不代表永远不能定量，建立外部测量与力学映射后可另行评估。[P1，第 6.1 节]

用受控工装、已知载荷或适当传感器构造短接触、持续接触、不同方向、姿态和速度。保留长时间无接触运动，避免只测容易检出的强接触。人工不得置于运动夹点；接触操作范围和停止条件预先确定。

### 8.2 阈值选择

在独立无接触标定数据上查看 L1 分数，以高分位数作为候选，再用带标注接触事件选取 T_high 与 T_low。分位数不直接保证每分钟误报率，尤其在时间相关噪声下。滤波、归一化打分或去抖都应明确公式并固定参数。

调参只使用标定集，冻结后在另一组轨迹测试；不得在最终测试上反复选最优。记录阈值、最短持续时间、滞回宽度、滤波延迟和标定数据哈希。

### 8.3 事件级指标

给每次真实事件标注起止、方向和置信度，预定义起点容差或重叠匹配规则。预测段与真实事件一对一匹配，未匹配预测为误触发，未匹配真实事件为漏检。长时间假接触另报持续时间。

输出事件级 precision、recall、F1、每分钟无接触时间的误触发数、匹配事件延迟中位数与 P95。样本级 F1 仅作补充，不与事件检出率混用。检测延迟会影响 PC 标注，应同步查看视频或参考信号。

### 8.4 工程目标与统计区间

建议起始目标为 recall≥90%、误触发≤1 次/分钟、延迟 P95<100 ms，再按任务需要调整并冻结。20 次接触只够初测，18/20 不意味着总体可靠达到 90%。正式验收覆盖多批次并给出区间。

零误报也要报告观察时长。若采用独立泊松事件近似，零误报的 95% 上界约为 3/T（T 为分钟）；相关事件不满足假设时，应延长观测或按 episode 重采样。所有统计假设应披露。

### 8.5 绝对接触精度

参考 wrench 经坐标变换和接触点雅可比映射到关节后，与同一时间轴上的预测比较。附逐关节 MAE、偏置、P95、参考量程、标定不确定度与有效事件数。明确比较原始还是滤波残差，不以强平滑隐去迟滞。

## 9 FIRST 标注与采样

### 9.1 逐轨迹标注

逐 episode 运行冻结 NEXT 与检测器，保留原始残差、滤波残差、实际分数及 FS/PC/C 标签。开头已经接触时可标 C，但不能补出录制前的 PC；起点在录制前应记为未知。接触标签优先，前窗口不跨轨迹。

离线利用未来接触起点标记此前 1 秒，是合法的训练标签构造；在线策略不能因此访问未来观测。示教中的真实接触、保护干预和外界扰动应有可追溯区分。

### 9.2 动作块和训练预算

以当前观测时刻为样本锚点赋权。动作块长度 30 时，末尾不足的样本需明确丢弃或 padding mask，不跨轨迹拼接动作。权重选择只用验证结果，不能直接在最终测试上寻找最佳比例。

报告原始与采样后阶段占比、抽样是否有放回、总步数、有效动作块数及种子。带权抽样不等于再给损失乘权，两者同时改变后不能仍称“只改采样”。各组固定训练预算，以免更多重复训练成为混杂因素。

### 9.3 标注验收

抽查短接触、持续接触和不同姿态，将视频、残差、分数和标签对照。确认 PC 名义 1 秒、C 不被覆盖、无跨段传播。发现伪接触先检查信号和阈值，不能只手工改成理想比例。

### 10.1 完整设定与最小版本

| 项目 | 论文设定 | 最小趋势验证建议 |
| --- | --- | --- |
| 平台 | 双臂 Piper | 单臂加固定工装 |
| 任务 | 五个长时序接触任务 | 一个可重复接触任务 |
| 示教 | 每任务 250 条 | 50 至 80 条试验性数据起步 |
| 视觉 | 两路腕部与两路顶视 | 依遮挡设置一至两路 |

| 动作 | 绝对关节角与夹爪，块长 30 | 单位、频率、限位明确 |
| 评价 | 每策略每任务 20 次 rollout | 先调通，再增加重复与种子 |

### 10.2 四组对照

| 组别 | 力矩输入 | FIRST 重采样 |
| --- | --- | --- |
| A 基础策略 | 否 | 否 |
| B 仅力矩输入 | 是 | 否 |
| C 仅重采样 | 否 | 是 |

四组共用示教、视觉处理、基础架构、训练预算与评估分布。C、D 使用同一个冻结 NEXT 的标签。新增输入模块如增加参数量，需记录。论文附录 D.5 也考察不输入力矩时的重采样收益。[P1]

### 10.3 评分和统计

训练前固定任务阶段、成功、超时、人工干预和异常如何计分。报告整任务成功率与阶段进度，简化任务分数不与论文五任务直接横比。尽可能盲评，保存视频与争议处理记录。

建议至少三个训练种子起步，各组共享可重复初始条件并随机化测试顺序，控制温度、物体磨损和操作者影响。成功率报告二项区间，进度按 rollout 或种子分组统计；同一 rollout 的阶段不能当作独立重复。

不预先保证 D>B>A，也不保证单臂收益一定小于论文。区间过宽时报告不确定性，决定追加样本；不以强制“提升 10 个百分点”取代真实结果。测试数据不能参与 checkpoint 或权重选择。

### 10.4 数据效率与失败分析

比较不同示教数量时固定或嵌套选取数据子集，避免质量差异被误解释为重采样收益。按视觉遮挡、对齐失败、接触误判、力矩延迟、动作限位和任务恢复分类保存失败，帮助判断瓶颈是否在 FIRST 能解决的范围内。

## 11 L3 可选力反馈遥操作

论文反馈框架不仅是一条比例公式，还需要可施力主臂、映射、重力与摩擦处理及稳定控制。[P1，附录 A.5] 被动位置读数装置无法仅靠软件产生物理反馈，原厂主从设置也不自动完成论文系统。

先检查主从方向、关节映射、力矩限幅、通信延迟和失联行为，再以低增益验证。看门狗、阻尼、渐入和急停独立测试，只有新鲜且有效的估计可进入反馈。异常时进入验证过的安全状态，而非只依赖 finally。

作者可选示例含门控与滤波保护，其说明明确这些附加机制不是论文实验原始设置。[C1] 使用时记录实现差异，不把示例增益直接视为本机安全参数。

比较无反馈、位置差反馈和 NEXT 反馈，随机化顺序并控制练习效应。分别报告易用性、时间、失败次数和力矩统计。若“施力更小”仍由同一个未标定模型测量，需承认参考不独立，不能据此单独证明真实力下降。该分支不阻塞 FIRST 实验。

## 13 故障排查

| 现象 | 优先检查 | 处理方式 |
| --- | --- | --- |
| 残差量级异常 | mA/A、度/rad、K 与符号 | 回查原始帧和已知载荷 |
| 运动误差大 | 同步、指令语义、覆盖 | 分项排查并重做对齐 |
| 静态偏置随姿态变 | 负载、校准、模型范围 | 不用单常数掩盖姿态误差 |
| 测试误差异常低 | 重复轨迹、跨界窗口、尺度缩小 | 审计切分和物理单位 |
| 接触尖峰后塌陷 | 保护、限幅或真实脱离 | 标记事件并保留原始信号 |
| 长时漂移 | 温度、负载、隐状态 | 检查重置并评估重训 |
| FIRST 无提升 | 标签、预算、任务瓶颈 | 查看四组对照和区间 |
| 基线异常差 | URDF、负载、滤波、增益 | 修复后重新公平比较 |

降频或硬件差异导致误差变化，不自动推翻论文；低自由空间误差也不自动支持全部结论。结论限定到实际测试条件，保留负结果与未决项。

## 14 资源与排期

L0 至 L2 最小配置为一台兼容 PiPER、可靠 CAN 接口、控制主机、固定工装与接触参考手段；绝对精度要求额外测量。L3 需要可主动反馈力的主臂。L4 的双臂、相机、末端和示教配置由任务决定，严格复现论文五任务的资源明显更多。

初步可为设备核验、通信适配、数据和首轮 NEXT 留出 1 至 2 周规划缓冲，但这不是交付承诺。标定或固件问题优先解决，不能用论文“1 分钟训练”估计项目工时。策略阶段按实测示教采集与 rollout 时长重排计划。

暂不列未核验价格。先决定需要证明的结论，再采购第二台臂、传感器或 GPU；仅验证自由空间预测不必购齐完整双臂平台。

## 附录 B 离线参考代码

本附录只说明单位、窗口、指标和阶段逻辑，不连接或驱动机械臂，也不替代官方训练器。输入须先通过 L0；在线控制不能从这些片段直接拼接。

### B1 单位换算

```python
import numpy as np

def convert_units(q_mdeg, cmd_mdeg, speed_mrad_s,
                  current_mA, effective_K):
    q = np.deg2rad(np.asarray(q_mdeg, float) / 1000.0)
    cmd = np.deg2rad(np.asarray(cmd_mdeg, float) / 1000.0)
    dq = np.asarray(speed_mrad_s, float) / 1000.0
    current = np.asarray(current_mA, float) / 1000.0
    K = np.asarray(effective_K, float)
    arrays = (q, cmd, dq, current, K)
    if any(a.shape != (6,) for a in arrays):
        raise ValueError("Expected six joints")
    if not all(np.isfinite(a).all() for a in arrays):
        raise ValueError("Invalid measurement")
    return q, dq, cmd, current, current * K
```

输入是假定已正确解码的字段。该函数不能修复错误的有符号解码或电机侧和关节侧混用，K 必须已经包含当前设备所需的方向定义。

### B2 单条轨迹的因果窗口

```python
import numpy as np

def make_windows(q, dq, cmd, tau, history=25):
    q, dq, cmd, tau = [np.asarray(a, float)
                       for a in (q, dq, cmd, tau)]
    if q.ndim != 2 or q.shape[1] != 6:
        raise ValueError("Expected (N, 6)")
    if any(a.shape != q.shape for a in (dq, cmd, tau)):
        raise ValueError("Shape mismatch")
    if not all(np.isfinite(a).all() for a in (q, dq, cmd, tau)):
        raise ValueError("Invalid sample")
    if history < 1 or len(q) < history:
        raise ValueError("Insufficient history")
    features = np.concatenate((q, dq, cmd - q), axis=1)
    x = np.stack([features[i-history+1:i+1]
                  for i in range(history-1, len(q))])
    return x, tau[history-1:].copy()
```

每个 episode 单独调用，先切分再构窗。大数据可使用惰性索引；有效段中存在缺失区时先切段，不跨越断点。

### B3 物理单位误差

```python
import numpy as np

def torque_metrics(predicted, reference):
    pred = np.asarray(predicted, float)
    ref = np.asarray(reference, float)
    if pred.shape != ref.shape or pred.ndim != 2:
        raise ValueError("Expected equal (N, J) arrays")
    if not pred.size or not np.isfinite(pred - ref).all():
        raise ValueError("Empty or invalid data")
    error = pred - ref
    absolute = np.abs(error)
    return {
        "mae_Nm": float(absolute.mean()),
        "per_joint_mae_Nm": absolute.mean(axis=0).tolist(),
        "per_joint_bias_Nm": error.mean(axis=0).tolist(),
        "per_joint_p95_Nm": np.quantile(
            absolute, 0.95, axis=0).tolist(),
    }
```

自由空间比较 tau_free_hat 与 tau_measured；接触精度比较 tau_external_hat 与独立参考关节力矩，不能混淆参考定义。

### B4 单条轨迹的相位标签

```python
import numpy as np

def label_phases(tau_ext, high, low, fps=50, pre_sec=1.0):
    tau = np.asarray(tau_ext, float)
    if tau.ndim != 2 or not len(tau) or tau.shape[1] < 1:
        raise ValueError("Expected nonempty (N, J)")
    if not np.isfinite(tau).all():
        raise ValueError("Invalid torque")
    if not (0 <= low < high and fps > 0 and pre_sec >= 0):
        raise ValueError("Invalid thresholds or time scale")
    score = np.abs(tau).sum(axis=1)
    contact = np.zeros(len(score), dtype=bool)
    active = False
    for i, value in enumerate(score):
        if value >= high:
            active = True
        elif value <= low:
            active = False
        contact[i] = active
    phase = np.where(contact, 2, 0).astype(np.int8)
    starts = contact & ~np.r_[False, contact[:-1]]
    count = int(round(pre_sec * fps))
    for onset in np.flatnonzero(starts):
        section = phase[max(0, onset-count):onset]
        section[section == 0] = 1
    return score, contact, phase
```

FS=0、PC=1、C=2，输入是单 episode 等间隔有效样本。滤波应在调用前按冻结参数完成。非等间隔数据应修复时轴或按实际时间构造前窗口。

### B5 带权采样

```python
import numpy as np

def sample_indices(phase, size, rng, weights=(1.0, 5.0, 1.0)):
    labels = np.asarray(phase)
    values = np.asarray(weights, float)
    if labels.ndim != 1 or not len(labels):
        raise ValueError("Expected nonempty labels")
    if not np.isin(labels, [0, 1, 2]).all():
        raise ValueError("Unknown phase")
    if values.shape != (3,) or not np.isfinite(values).all():
        raise ValueError("Invalid weights")
    if np.any(values <= 0):
        raise ValueError("Weights must be positive")
    mass = values[labels.astype(int)]
    return rng.choice(len(labels), size=size, replace=True,
                      p=mass / mass.sum())
```

训练器建立一次带种子的 np.random.default_rng，并持续传入该 RNG，不在每个 batch 重置种子。标签须已筛选为有合法动作块的样本。
