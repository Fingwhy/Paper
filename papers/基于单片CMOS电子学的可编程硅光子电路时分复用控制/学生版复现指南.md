## 0. 先说清楚边界：哪些能复现，哪些不能

这篇论文的硬件门槛极高——它要在商用 220 nm 硅光 MPW 流片上做**零改动**的 CMOS 集成，
一轮流片几十万起步，个人和课题组都玩不起。所以"复现"在这里只能是**分级**的：

| 内容 | 能否复现 | 替代做法 |
|---|---|---|
| 流片、SEM 照片、实测 I-V | ❌ 完全不可能 | 读器件物理，做一阶模型 |
| MUX 建立时间、开关频率 | ✅ 可算 | 单极点 RC + 反推 |
| S&H 保持时间、电荷注入预算 | ✅ 可算 | 电荷守恒手算 + 脚本 |
| 抖动锁定、10 ms 配置、混叠 | ✅ 可仿真 | Python 状态机 / 环路仿真 |
| 10 Gbit/s BER、0.3 dB 代价 | ⚠️ 只能等效 | 功率代价模型，不是真实 BERT 测量 |

**给学生的诚实定位**：这是一个"用一篇好论文练建模与量纲分析"的项目，不是"复现实验"。
报告里绝不能写"我复现了该芯片"，只能写"我用一阶模型核对了该文的 N 个关键指标，偏差来自 X、Y"。

## 3. 四个阶段（每阶段 1–2 天）

### 阶段 1｜器件级：为什么这管子必须做成"侧栅"

**先想明白一件事**：硅光平台的 220 nm 硅层是给波导用的，它只有 220 nm 厚，
而正常 MOS 的沟道宽度就是这 220 nm。于是宽长比 W/L = 220 nm / 4 µm ≈ **0.055**，
比常规工艺小三个数量级——**单管电流只有 0.2 µA 量级**，这正是论文里功率管要 700 只并联的原因。

要做的：

1. 用亚阈值指数 + 平方律 + 沟道长度调制写一个 `id_nmos(vgs, vds)`。
2. 三个参数**必须**取自论文：Vth = 2.45 V、反亚阈值斜率 350 mV/dec、厄利电压 35 V。
3. **μCox 不能拍脑袋**。先由栅氧厚度算 `Cox = εox/tox = 0.173 mF/m²`，
   再乘轻掺杂硅的电子迁移率 1400 cm²/Vs → `μCox ≈ 24 µA/V²`。
   > 这一条是踩过的坑：直接取 1.45 mA/V² 会反推出 84000 cm²/Vs 的迁移率，
   > 报告交上去就是硬伤。**任何"假设参数"都要能反推回物理量自检**。

**验收**：开/关比 > 1e6；700 管并联在 12 V 下的电流与论文实测 11 mA 同量级。

实测输出（脚本直接给）：

```
Cox (mF/m^2)               0.1725    由 tox=200 nm 算
μCox (µA/V^2)              24.15     μ=1400 cm^2/Vs × Cox
Ion @Vgs=3V,Vds=2V (µA)    0.2124    本模型
开/关比                    1.384e+08 本模型
单管线性区 Ron @Vgs=3V     1.501 MΩ  本模型
700 管并联 @Vgs=12V        24.38 mA  对论文 §4 的 11 mA  ← 同量级，差 2.2 倍
```

那 2.2 倍的差怎么解释？源极跟随器接法损失了 Vgs、高场下迁移率下降、版图串联电阻。
**把差异归因清楚，比数字对得上更有价值。**

### 阶段 2｜MUX：把那组"矛盾"的数拆开

论文同时给了两个数：**单开关带宽 ≈100 MHz**，但**改配置位的建立时间 ≈500 ns**。
这两个数放在一起是不自洽的——你先自己验一遍：

- 若 500 ns 是单极点 RC 建立到 0.1%（≈6.9 τ），则 τ = 72 ns；
- τ = 72 ns 对应的带宽只有 **2.2 MHz**，比 100 MHz 低 45 倍；
- 反方向：若带宽真是 100 MHz，建立时间应该只有 **11 ns**。

```bash
python3 code/sim_core.py    # 阶段 2 直接把这三行打出来
```

**结论（也是这道题的正解）**：500 ns 不可能来自模拟通路的 RC，因为光电流通路上
负载只是 TIA 输入的几个 pF。它更可能来自**数字地址译码 + 栅极驱动 + TIA 建立**这条慢路径。
论文没给开关尺寸和负载电容，你只能把这个结论写成"推断"，不能写成"证实"。

顺带验收时分复用的合法性：

```
每路采样率 = 80 kHz / 4 = 20 kHz      (论文 §5)
抖动频率 2 kHz / 20 kHz = 0.1         (远小于 0.5，不会混叠)
```

> **思考题**：如果想让抖动频率提到 20 kHz 以提高跟踪速度，MUX 至少要开到多少？
> 论文 §5 说 MUX 支持更高开关率（受限于外部板子），这句话怎么验证？

### 阶段 3｜S&H：0.03 dB 翻译成一个电路指标

这是全篇最值得练的一段——**把光学指标翻译成电子指标**。链条如下：

1. 论文说 12 V 对应 3π 相移 → 灵敏度 dφ/dV ≈ 0.785 rad/V（一阶线性外推）。
2. 工作点偏置在最小透射点 −26 dB → 归一化功率 2.5e-3。
3. 允许 0.03 dB 退化 = 该功率的 0.69% → ΔP/Pmax ≈ 1.7e-5。
4. 由 MZI 传输函数斜率反推 → 允许相位漂移 ≈ 0.35 mrad → **允许保持电压误差 ≈ 0.44 mV**。
5. 存储电容 10 pF → **允许的注入电荷 ≈ 4.4 fC**。

于是"0.03 dB"这个看起来无关痛痒的数，变成了一条硬指标：
**你的开关每次断开，注入到 10 pF 上的电荷必须小于 4.4 fC。** 这正是论文里
"残余误差来自电荷注入"那句话的定量版本。

保持时间同理：允许栅压跌落 0.1 V、保持 1 s → 漏电必须 < 1 pA（等效泄放电阻 5.5 TΩ）。
学生常犯的错是把"1 s 保持"当成仿真常数，其实它是**由漏电和电容算出来的**。

**验收**：手算与脚本结果一致；能解释为什么"电荷注入"和"漏电"是两个独立机制。

### 阶段 4｜系统级：10 ms 能不能配完

论文 §5 给了一串频率：抖动 2 kHz、MUX 80 kHz、每路 20 kHz、16 输入 × 4 层二叉树。

要做的（一个几十行的 Python 状态机就够）：

1. 每个 MZI 用一个积分控制器，输入是抖动解调出的斜率符号；
2. 更新率 = 20 kHz，10 ms 内可迭代 200 次 → 一阶收敛 `(1-kp)^200` 早就到 1e-31；
3. 所以 **10 ms 不是收敛极限，而是"攒够信噪比所需的积分时间"**——这个区分很重要：
   收敛速度不是瓶颈，抖动解调的 SNR 才是。

**验收**：能说清"为什么是 10 ms 而不是 1 ms 或 100 ms"（答：抖动幅度要小到不损伤信号，
所以解调必须积分足够长时间；10 ms 是光路带宽与信噪比的折中）。

## 4. 交付物建议

一份 6–10 页的报告，包含：

1. **建模假设表**：每个"论文没给、我假设了"的参数，写清取值依据与自检方式。
2. **对照表**：论文值 / 你的值 / 偏差 / 偏差归因（这是全文核心）。
3. **三张图**：I-V 曲线（对 Fig.1e）、MUX 建立波形（ngspice 或手算曲线）、
   0.03 dB 预算的敏感度曲线（ΔV 从 0.1 mV 扫到 10 mV）。
4. **一段"我复现不了什么"**：流片、SEM、真实 BER——写清楚比藏着好。

## 5. 三个最容易翻车的点

| 坑 | 表现 | 怎么避 |
|---|---|---|
| 参数不自检 | μCox 随手取，反推出非物理迁移率 | 每个假设都反推回物理量看量级 |
| 把推断当结论 | "500 ns 来自数字延迟"写成定论 | 论文没给的部分一律写"推断/假设" |
| 单位串台 | 把 µA 当 mA，开/关比差 1e3 | 脚本里全部用 SI 基本单位，只在打印时换算 |
