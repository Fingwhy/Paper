## 每个文件夹里有什么

`中文译稿.html` 是排版源文件；其余是支撑材料与复现材料。

## 几点说明

- **原文 PDF 不重复存**：`arXiv:2606.12406` 的原文在 `解析与复现/paper/`；另两篇原文未随仓库分发，按上表链接自取。
- **译文有缺口会标出来**：硅光子那篇的内嵌公式数值（掺杂浓度、增益因子、MUX 面积等）在 Wiley 网页上是 MathML 渲染的，
  抽取后只剩空括号，译文逐处标注「数值缺失」，没有编造。
- **「解析」和「复现」是两件事**：解析是对论文的拆解，含我的判断（比如哪组数据自相矛盾）；复现是能跑的代码或实验记录。
- **复现材料里的原始数据不入库**：`解析与复现/experiments/` 只留报告与脚本，原始帧、模型权重按 `.gitignore` 排除，
  需要时按各阶段报告里的命令重跑。
- 译文仅供阅读，引用请以期刊 / arXiv 原文为准。

## 重新生成译文 PDF

译文 HTML 改完后用 Edge 无头模式打印（本机没装 Chrome 也能用）：

```bash
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" \
  --headless=new --disable-gpu --no-pdf-header-footer \
  --print-to-pdf="输出.pdf" --virtual-time-budget=8000 "file:///绝对路径/中文译稿.html"
```
