# FACTR 2 幻灯片讲解手册

> 与《FACTR 2 论文解析与 PiPER 复现》19 页逐页对应：每页给一段可照着念的讲稿、一张名词表、一张数字表。数字全部标注出处，估读与推断单独标出。

## 0 怎么用这本册子

每一节对应一张幻灯片，三块内容固定：

- **这一页在讲什么**：现场可直接念的讲稿，约 100 至 150 字，不含"这一页展示了"之类的元描述。
- **名词**：这张幻灯片上出现的术语，按出现顺序解释。跨页重复的只在该页做简短说明，完整定义查附录 A。
- **数字**：这张幻灯片上的每一个数值，标明含义、出处、怎么读。凡不是论文原文表格给的，会在出处栏写清是"估算"还是"由某两数算出"。

三条使用建议。第一，讲的时候先念讲稿，再挑名词表里听众最可能卡住的一两个展开，不要全部念完。第二，数字表是答辩防守用的，被追问出处时直接翻到这里。第三，附录 C 的三条口径提醒务必先看，这是整份材料最容易被挑错的地方。

## 1 第 1 页 · 封面

### 这一页在讲什么

这篇论文要解决的问题一句话能说完：没有力传感器的机械臂，怎么知道自己被多大的力顶着。作者给了两个模块，NEXT 负责把外力矩估出来，FIRST 负责用这个信号改进策略学习。封面上三个数字是先给结论：接触段误差 0.547 牛米、空载贴零 0.018 牛米、策略收益至少 17%。

### 名词

| 名词 | 含义 |
| --- | --- |
| FACTR 2 | 论文标题的简称，全称 Learning External Force Sensing for Commodity Robot Arms Improves Policy Learning，是前作 FACTR 的续作 |
| NEXT | Neural External Torque，神经外部力矩估计器，本文的第一个贡献 |
| FIRST | Force-Informed Re-Sampling Training，力信息驱动的重采样训练，本文的第二个贡献 |
| 商品级机械臂 | commodity robot arm，指可批量采购、价格低、但不带关节力矩传感器的机械臂，PiPER 属于这一类 |
| 关节力矩 | 作用在单个关节旋转轴上的力矩，单位牛米，和末端六维力不是一回事 |

## 2 第 2 页 · 三个数字，三种口径

### 这一页在讲什么

这三个数经常被并排引用，但它们量的根本不是一回事。0.547 是拿传感器当真值算出来的误差，回答"估得准不准"；0.018 是拿零当真值算出来的漂移，回答"没人碰的时候会不会乱报"；17% 是策略跑出来的任务进度差，回答"这东西到底有没有用"。三者不能互相背书，尤其不能拿 0.018 去暗示接触精度。

### 名词

| 名词 | 含义 |
| --- | --- |
| L1 误差 | 各分量绝对值的和（或平均），对六维关节力矩就是六个关节绝对误差求和；论文表格里报的是平均值 |
| 真值 | 用来对比的参考量。接触段用 Franka 自带的外力矩估计，自由空间直接取 0 |
| 自由空间 | 机械臂运动过程中不与任何物体接触的状态 |
| 力感知基线 | 已经使用了某种力或接触信号的策略，比如 TA-VLA、FACTR，不是指不用力的 Base 策略 |
| 口径 | 这个数值是在什么真值、什么数据集、什么指标下算出来的 |

## 3 第 3 页 · 力觉很贵

### 这一页在讲什么

接触富操作离不开力信息，但"有力"和"用得起"是两件事。一台 PiPER 两三千美元，一台 Franka 三万美元，再给末端加一个六维力传感器，成本可能又翻一截。就算不加传感器，走传统路线也有四道坎：参数要逐台标定、残差里混着未建模效应、异常检测只能判断有没有碰撞、监督式方法还要昂贵的接触标注。FACTR 2 的策略是绕开这四件事。

### 名词

| 名词 | 含义 |
| --- | --- |
| 六维力传感器 | 能同时测三个方向力与三个方向力矩的末端传感器，装在手腕处 |
| 系统辨识 | 用实验数据拟合机械臂的质量、质心、摩擦等动力学参数 |
| 未建模效应 | 解析模型里没有、也很难写进公式的物理现象 |
| 齿隙 | 齿轮啮合间隙，换向时会出现空程 |
| 滞回 | 加载与卸载走不同曲线，谐波减速器尤其明显 |
| 力矩纹波 | 电机与减速器造成的周期性力矩波动 |
| 死区 | 输入很小但输出没有响应的区间 |
| 接触标注 | 人工标出哪一段是接触、哪一段不是，用于监督学习 |

## 4 第 4 页 · 方法总览

### 这一页在讲什么

整个方法两句话能讲完。NEXT 做的事是估计：它不去算动力学模型，而是学一个"空载时这个关节本该出多少力"的预测器，再从实测力矩里减掉。FIRST 做的事是采样：用估出来的外力矩把示教切成三段，让接触前那一段在训练里出现得更频繁。两者是解耦的，可以分开验收、分开替换，这也是复现时能拆成阶段做的前提。

### 名词

| 名词 | 含义 |
| --- | --- |
| τ_m | 电机实际输出的关节力矩，由电流乘力矩常数换算 |
| τ_ext | 外部力矩，接触造成的、扣掉自重与摩擦之后剩下的那部分 |
| f_θ(x) | 用参数 θ 的神经网络预测的空载力矩，也记作 τ̂_f |
| 解耦 | 两个模块各自独立，一个出错不会掩盖另一个的问题 |

### 数字

| 数字 | 含义 | 出处 |
| --- | --- | --- |
| 10 分钟 | NEXT 训练数据量，无接触采集 | 论文第 4 节 |
| 1 分钟 | 单卡训练时间 | 论文第 4 节 |

## 5 第 5 页 · 三个公式

### 这一页在讲什么

三个公式分别管三件事。第一式是部署时的减法：实测总力矩减去空载预测，剩下就是外力。第二式规定网络看什么：位置、速度、指令与实际的差，各取最近 H 帧，不能只看当前一帧，因为摩擦和滞回是有记忆的。第三式是训练目标：平方 L2，标签直接用实测力矩，因为采集时故意不接触任何东西，此时外力为零，实测力矩本身就等于空载力矩。

### 名词

| 名词 | 含义 |
| --- | --- |
| τ_m = K · I_m | 用电流乘力矩常数得到关节力矩，K 由标定确定 |
| Δq_d | 指令位置减当前位置，即跟踪误差，反映控制器正在多用力去追指令 |
| H | 历史窗口长度，单位是帧 |
| 平方 L2 | 各分量残差平方后求和，不取根号 |
| 无标签监督 | 不需要人工标注，标签由传感器读数本身提供 |

### 数字

| 数字 | 含义 | 出处 |
| --- | --- | --- |
| H = 50 | 论文使用的历史长度 | 论文表 3、附录 D.1 |
| 0.5 秒 | H=50 在 100 Hz 下对应的时长 | 由 50 ÷ 100 算出 |
| 100 Hz | 论文的部署与控制频率 | 论文第 4 节 |

## 6 第 6 页 · 部署链路

### 这一页在讲什么

部署时整条链路只有三步：读电流、乘 K 得力、减去网络预测。网络本身很小，两层 LSTM 加两层 MLP，输入是 50 帧的窗口，一次前向 1.76 毫秒，相当于 568 赫兹，实际按 100 赫兹跑还有大量余量。值得注意的是它用滑动窗口而不是跨整条轨迹的隐状态，这样做是为了避免长轨迹上隐状态漂移，代价是每次都重算窗口。

### 名词

| 名词 | 含义 |
| --- | --- |
| LSTM | 长短期记忆网络，擅长处理时序与带记忆的效应 |
| MLP | 多层感知机，把 LSTM 的输出映射成六维力矩 |
| 隐藏维度 128 / 256 | 每层神经元数量，代表模型容量 |
| 隐状态 | LSTM 内部保存的历史记忆；本文改成无状态滑动窗口 |
| 推理延迟 | 一次前向计算耗时，1.76 毫秒 |
| 帧 | 一次采样得到的六个关节数据 |

### 数字

| 数字 | 含义 | 出处 |
| --- | --- | --- |
| 2 层 LSTM，隐藏 128 | 网络结构 | 论文表 3 |
| 2 层 MLP，256 | 网络结构 | 论文表 3 |
| H = 50 | 输入窗口帧数 | 论文表 3 |
| 约 6 万帧 | 10 分钟按 100 Hz 采样 | 由 10 × 60 × 100 算出 |
| 1.76 ms | 单次前向耗时 | 论文附录 A.1 |
| 568 Hz | 1 ÷ 0.00176 得到的等效频率 | 由 1.76 ms 算出 |

## 7 第 7 页 · FIRST

### 这一页在讲什么

FIRST 只有四步。先逐帧算接触分数，也就是六个关节外力矩绝对值的和；再用双阈值滞回判断此刻算不算接触，高阈值进入、低阈值退出，避免在阈值附近反复翻转；然后给每一帧打上自由运动、接触前、接触三个标签，接触前的定义是接触起点往回一秒；最后按权重重新采样，四个任务用 1:5:1，需要持续接触的拧瓶盖用 1:3:3。

### 名词

| 名词 | 含义 |
| --- | --- |
| 接触分数 f_t | 六个关节外力矩绝对值之和，一个标量，越大说明接触越强 |
| L1 范数 | 向量各分量绝对值之和，这里刻意不用平方和，避免单个大关节主导 |
| 双阈值滞回 | 用两个阈值判断状态，进入和退出用不同门槛，防止抖动 |
| 接触前 | 接触起点之前的一段固定时长，论文取 1 秒 |
| 重采样权重 | w_F : w_PC : w_C，分别是自由运动、接触前、接触的采样概率权重 |
| 加权采样 | 按权重从数据集里抽 batch，不改损失函数 |

### 数字

| 数字 | 含义 | 出处 |
| --- | --- | --- |
| 1 : 5 : 1 | 四个任务使用的最优权重，接触前被放大 5 倍 | 论文表 8 |
| 1 : 3 : 3 | 拧瓶盖任务的最优权重 | 论文表 8 |
| 1 秒 | 接触前窗口长度 | 论文第 5 节 |
| m ≈ 5 | 上采样倍率，附录扫描显示 5 附近见顶 | 论文附录 D.4 |

## 9 第 9 页 · 用户研究

### 这一页在讲什么

这一页回答的是"没有传感器，人能不能感觉到力"。20 名被试、5 种反馈条件、1 到 5 分的易用性评分，还有完成同样任务所需施加的力。结论是 NEXT 的评分接近带真传感器的方案，明显好于无力反馈；所需施加的力更小，说明操作者更有把握、不用靠蛮力试探。在 PiPER 上这件事的意义更大——这台机器根本买不到关节力矩传感器，所以它决定的是"能不能做力反馈"，而不是"做得准不准"。

### 名词

| 名词 | 含义 |
| --- | --- |
| 遥操作 | 人操作主臂，从臂跟随并回传力感 |

| 易用性评分 | 被试对某种反馈方式的主观打分，1 到 5 分 |
| 施加力矩 | 人为了让机械臂完成任务而主动施加的力，越低说明力觉越清晰 |

## 11 第 11 页 · 该加权的是接触前

### 这一页在讲什么

同样的策略、同一批数据，只改给哪一段加权，五个任务的结果就分开了。只给接触段加权是 0.670，几乎等于没加——接触已经发生，姿态错了就只能在错的位置上微调。只给接触前加权是 0.818，五个任务里四个最好。两段都加是 0.811，平均只差 0.7 个百分点，但在拧瓶盖上拿到最高的 0.825，因为它靠持续接触把螺纹拧下去。所以比例是分任务定的。

## 18 第 18 页 · 五个坑

### 这一页在讲什么

这五个错误都不会让程序崩溃，只会让最后的数字难看，然后你会从最后一个环节开始修。力矩常数没标定，整套估计整体缩放，接触阈值全部失效；自由空间混进一次擦碰，训练标签就被污染；阈值照抄论文，误报与漏报会同时出现；把关节力矩当末端力，控制的方向和量纲都会错；任务进度靠人工划段，跨任务就没法比。前三个决定信号能不能用，后两个决定结论能不能信。

## 附录 C 三条口径提醒

**第一，任务进度不是成功率。** 论文报告的是按阶段完成度打分的结果，一个任务可能拿到 0.6 却没有一次完整成功。汇报时说"任务进度"而不是"成功率"，否则会被追问成功率是多少，而论文没有给。

**第二，柱状图上的数字是估读。** 图 6 没有标数值，任何"44% 涨到 85%""提升 41 个百分点"的说法都只能当量级看，误差在五个百分点量级。引用时务必加"约""估读"。

**第三，PiPER 上的 0.018 不是接触精度。** 它是在自由空间里对着零算出来的，只能证明"没人碰时不乱报"。想在 PiPER 上报接触误差，必须先自建标定台，用已知质量块或弹簧拉力计造出可信的真值，否则这个数没有对手。
