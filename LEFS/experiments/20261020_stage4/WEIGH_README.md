# 称重应用使用说明（weigh_app.py）

> 放在 `~/stage0/20261020_stage4/weigh_app.py`
> 后端全部复用 `weigh_arm.py` 里已实测过的函数，本文件只做菜单和显示。

## 一、怎么启动

VM 上开一个终端：

```bash
weigh
```

如果提示找不到命令（说明 PATH 还没生效，新开终端即可），用：

```bash
cd ~/stage0/20261020_stage4 && ./weigh.sh
```

只想验算、不连机械臂：

```bash
cd ~/stage0/20261020_stage4 && python3 weigh_app.py --selftest
```

## 二、菜单六个功能

| 键 | 功能 | 什么时候用 |
| --- | --- | --- |
| 1 | 状态 | 看夹爪开度、关节角 |
| 2 | 张开 | 要往夹爪里放东西（可指定开度，默认 70 mm 全开） |
| 3 | 夹紧 | 东西已放好，手动夹住（可指定力度 100~2000） |
| 4 | **称重·准** | **首选**。跑两个姿态，不用预标定，误差 3~6.5% |
| 5 | 称重·快 | 同一个物体复称，只跑一个姿态，300 g 以上约 2% |
| 6 | 一键称重 | 张开→等你放→夹紧→自动称（双姿态） |
| 7 | 历史 | 最近 12 次称重记录 |
| 8 | 环境自检 | CAN 没起来 / 连不上臂时先看这里 |
| 9 | 清理 | 夹爪一直抖，多半是有旧进程在抢控制权 |

## 三、两种称法怎么选

**第一次称一个物体 → 用 4（双姿态）**

不需要事先知道任何东西，还能顺便算出这个物体的质心在哪。
误差：300 g 约 3%、500 g 约 5~6.5%。

**同一个物体再称 → 用 5（单姿态，快一倍）**

借用了之前标定好的质心，只跑一个姿态。
实测：300 g +1.7%、500 g +1.8%。**但 100 g 会偏 25%，太轻的别用。**

## 四、什么时候结果不可信

1. **太轻**：100 g 产生的力矩和电流噪声一个量级。要用 4，且误差仍会到 20% 以上。
2. **夹的位置变了**：重量和质心是一起算的，夹持点挪十几毫米，质量能差 15%。
   所以复称同一个物体时，**夹同一处**。
3. **有液体**：水在晃会让读数漂，静置几分钟再称。
4. **姿态差 > 1.5°**：程序会打印警告，说明采集时被别的进程干扰或没走到位，重称。

## 五、安全（程序里写死的）

- 夹爪闭合永远「每 1.5 mm 一步、碰到即停、再压 0.6 mm」，不会一步夹死；
- 默认夹持力 1.2 N·m，要改必须在菜单里显式输入；
- **J6 行程是单侧的 [0°, +343°]，0° 是硬端点**，程序不会让 J6 往负方向走；
- Ctrl+C 中断不会失能机械臂，只是不再发指令；
- **断电前一定要用手托住**：实测断开电源时六轴会自由落体。

## 六、改参数

夹爪全开行程、夹持力、等你放物体的秒数、每个姿态静止多久，
都在 `weigh_arm.py` 顶部的 `CFG` 里，改那几行就行：

```python
CFG = dict(
    open_mm=70.0,        # 张开行程 mm
    open_effort=400,     # 张开力限
    close_effort=1200,   # 夹持力限（0.001 N·m）
    hold_seconds=5.0,    # 张开放东西的等待秒数
    squeeze_mm=0.6,      # 接触后再压多少 mm
    hold_s=12,           # 每个姿态静止保持秒数（越长噪声越低）
    rec_s=30,            # 每个姿态录制秒数
)
```
