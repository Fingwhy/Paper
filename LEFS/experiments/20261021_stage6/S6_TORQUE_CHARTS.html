口径
  • 对齐：实测 VM 时钟比 Windows 慢 7.97 s。臂侧 raw 头的 started（VM 本地时间） +7.97 s 换到 Windows 时基，再与传感器头 t0_epoch 求差得 L， 映射为 臂时间 = 传感器时间 + L。
  • 转动窗：以 |dq6| > 0.3·max 判定 J6 真正在转的区间，只在窗内取均值与反解。
  • 传感器：一律 raw × 0.02774，不减零点（换夹具后零点会变，看增量更可靠）。
  • 三条力矩曲线： 蓝 = 实测（传感器）； 红 = 用 K6=10.7882 预测（K6·i6）； 橙虚线 = 用联立反解的 K 预测（K_fit·i6 + b）。 红蓝偏离 = K6 的误差；橙蓝贴合 = 该模型能达到的上限。
  • 物理预期：臂力矩 = 载荷 + 关节摩擦，所以「臂 / 实测」应略大于 1。
