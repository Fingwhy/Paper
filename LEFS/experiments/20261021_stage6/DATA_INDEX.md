## 3 `twist_*.csv` 字段说明（12 列，无表头行以外的元数据）

| 列号 | 字段 | 单位 | 说明 |

| 0 | `t_s` | s | 相对 twist 开始的秒数 |

## 4 电流口径（这一节最容易搞错）

```python
p.GetArmHighSpdInfoMsgs().motor_N.current * 0.001   # 单位 A
```

| 项 | 值 |
|---|---|
| CAN 帧 | **`0x251`~`0x256`**（高速帧），六轴各一帧 |
| 字段 | `current`（**不是** `motor_current`） |
| SDK 标注单位 | 0.001 A |
| 实际类型 | **int16 有符号**（SDK 文档写 uint16，是错的） |
| 采样率 | 200 Hz |

**绝对不能用** `GetArmLowSpdInfoMsgs().motor_N.bus_current`（`0x261` 低速帧）：
官方明确「1.5 kg 关节电机无采样，默认发 0」。`s3_j6_live.py` 用的就是它，是错的。

**电流方向**：正负号代表力矩方向，与关节转动方向和重力负载方向有关，没有统一约定，**只能同姿态下比较**。

## 5 精度：分辨率 vs 实测噪声（两回事）

### 5.1 分辨率

**0.001 A**（16 位量化步长）。这是能读到的最小刻度，**不代表精度**。

### 5.2 实测噪声（来自 `twist_z177.csv`，J1~J5 全程静止）

| 轴 | 均值 (A) | **标准差 (A)** | 峰峰 (A) | 0.5 s 滑动平均后 std |
|---|---|---|---|---|
| J1 | +0.0834 | **0.0159** | 0.097 | 0.0147 |
| J2 | −1.7846 | 0.0263 | 0.161 | 0.0236 |
| J3 | −0.8809 | 0.0395 | 0.284 | 0.0375 |
| J4 | −0.0348 | 0.0478 | 0.236 | 0.0456 |
| J5 | +0.0748 | **0.0866** | 0.396 | 0.0845 |
| J6（转动+负载） | −0.2126 | 0.0853 | 0.452 | — |
| **J6（尾部静止 30 帧）** | −0.1725 | **0.0704** | 0.293 | — |

**两个关键事实**：

1. **噪声随轴递增**（J1 0.016 → J5 0.087）。J1 最接近纯电噪声，末端轴混入了机械振动和重力前馈误差。
2. **滑动平均几乎无效**（J1 0.0159 → 0.0147，只降 8%）。说明噪声**不是白噪声**，主要是低频漂移（温漂、振动、前馈残差），多采几点平均不掉。

### 5.3 对 K6 换算的意义

J6 静止噪声 0.070 A，按 K6 = 10.79 折算：

```
τ_噪声 = 0.070 × 10.79 ≈ 0.76 N·m
```

**这就是为什么 I6 判据不可行** —— 瓶盖扭矩差异（1.45 → 0.99，差 0.46 N·m）比这个噪声地板（0.76 N·m）还小。

（注：这个 0.76 N·m 比阶段 4 报告的 0.111 N·m 大得多，因为这里的姿态 J5=66°、臂悬伸 350 mm，机械振动远比台面上的标定姿态大。）

## 6 换算公式

```
τ_motor = K6 × I6 − τ_摩擦
```

| 参数 | 值 | 来源 |
|---|---|---|
| K6 | **10.7882 N·m/A**（±0.4952，σ/K 4.6%） | `k6_result.json` |
| τ_摩擦 | **0.86 N·m** | 空载 ΔI = 0.160 A 反推 |

**注意**：这是**相对力矩**。绝对力矩不可用——J6 电流里混着固件重力前馈、温漂等不可分离项。

## 7 已知数据质量问题

| 问题 | 影响文件 | 说明 |
|---|---|---|
| 表头少一列 | `twist_r1/r2/r3`、`twist_cyc1~3` | 用位置索引读取 |
| 误拧紧 60° | `twist_fast2` | 夹爪夹着瓶盖回位所致，不可作为对比基线 |
| 参数未控制 | 大部分 `twist_*` | 夹持 effort 在 −385~−630 间随机波动，瓶盖初始扭矩每次不同 ⇒ **横向比较只能看趋势** |
| 无转角基准 | 全部 | 无法区分"瓶盖转了"还是"夹爪滑了" |
