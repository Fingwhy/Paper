# PiPER · FACTR 2 复现操作指南

> 配套文档：《PiPER 标准版 FACTR 2 复现实施报告》修订版 2.0
> 适用平台：AgileX PiPER 标准版（6 DoF，无关节力矩传感器，CAN 1 Mbps）
> 文档定位：执行手册。每一步做什么、拿什么验收、卡住查哪里；为什么这样做见实施报告

## 0 怎么用这本指南

| 你现在的状态 | 直接跳到 |
| --- | --- |
| 刚拿到机械臂，还没跑通 CAN | 第 2 章、第 3 章、第 4 章 |
| 能读数据，但不知道力矩对不对 | 第 5 章 |
| 要开始采数据训练 | 第 6 章、第 7 章 |

| 结果不对，怀疑哪里错了 | 第 12 章故障速查 |

一条总原则：**上一阶段的门没过，不要开下一阶段。** 本指南里每个阶段末尾都有一个「验收门」，门是硬的，不是建议值。

## 1 四道门：先想清楚要证明什么

复现 FACTR 2 不是「跑出一个数」，而是分别回答四个问题。四个问题需要四种证据，任何一个数字都不能替代另一个。

| 门 | 要回答的问题 | 需要的证据 | 最常见的假通过 |
| --- | --- | --- | --- |
| L1 自由空间 | 能不能准确预测无接触时的关节力矩 | 独立测试集上的关节平均 MAE、逐关节偏置与 P95 | 用训练集或相邻轨迹当测试集 |
| L2 接触检测 | 残差能不能识别真实接触 | 事件级 precision / recall、误触发率、延迟 | 只报样本级 F1，不报事件 |
| L2 尺度 | 残差是不是可信的物理力矩 | 独立参考（砝码或力传感器）+ 不确定度 | 用自由空间贴零反推 K |
| L4 策略 | FIRST 是否真的改善策略 | A/B/C/D 四组对照 + 区间 | 只跑 D 组，或改了训练预算 |

> 验收门：先写下你要证明哪几条，再决定买不买第二台臂、力传感器、相机。只验证自由空间预测，单臂 + 工装就够。

## 3 阶段 0：环境与版本冻结

预计半天。目标不是「程序能启动」，而是「每一步都能复现」。

**步骤**

1. 上电前核对供电与急停，机械臂置于行程中部、无障碍。
2. 连接 CAN，确认比特率 1 Mbps，示波或日志确认收到 `0x2A1` 心跳类反馈。
3. 读取固件版本并记录：
   ```python
   from piper_sdk import C_PiperInterface
   piper = C_PiperInterface("can0", judge_flag=False)
   piper.ConnectPort()
   print(piper.GetPiperFirmwareVersion())
   ```
4. 切从站模式（读反馈要求从站）：`piper.MasterSlaveConfig(0xFC, 0, 0, 0)`。
5. 使能六关节 + 夹爪：`piper.EnableArm(7)`；确认首帧默认值被丢弃后再进控制循环。
6. 冻结官方仓库版本：
   ```bash
   git clone https://github.com/philiphan0109/factr2_next.git
   cd factr2_next && git rev-parse HEAD > source_commit.txt
   ```
7. 把 2.3 的表填完，存入 `experiments/<run_id>/manifest.json`。

> 验收门：固件、SDK、官方实现三个版本号齐全；`source_commit.txt` 存在；从站模式确认；首帧丢弃逻辑已在代码里体现。

## 4 阶段 1（L0）：信号链与同步

预计 1 至 2 天。这一阶段决定后面所有数字的上限，返工代价最高。

### 4.1 七步落地

1. **原始层落盘**：只追加。每条记录保存 CAN ID、8 字节原始数据、接收时间、异常标记。不要在这一层解析。
2. **解析层**：按 `0x251~0x256` 解出六个关节的转速、电流、位置；按 `0x2A1~0x2A8` 取关节角与状态。
3. **统一单位**：位置 rad、速度 rad/s、电流 A、力矩 N·m。`0x2A5~0x2A7` 给的是 0.001 度整数，先转度再转 rad。
4. **构造 q_cmd**：用当前控制周期真正下发的参考位置。**不能用 q 代替**，否则跟踪误差恒为零，NEXT 少一路关键输入。
5. **时间对齐**：以已到达的观测对齐，逐样本记录各字段年龄与跨关节时间跨度。
6. **异常处理**：NaN、缺帧、过期、饱和、保护触发、指令中断，全部带标记保存，不静默填零。
7. **压测**：连续采集 10 分钟「静止 + 低速安全运动」。

### 4.2 帧定义与三个坑

| 项 | 值 |
| --- | --- |
| 高速反馈 | `0x251~0x256`，20 ms 名义周期，即 50 Hz |
| 字节 0–1 | 转速，int16，0.001 rad/s |
| 字节 2–3 | 电机电流，uint16，0.001 A |
| 字节 4–7 | 位置，int32，rad |
| 字节序 | Motorola（MSB 在前） |

- **坑一：调用频率不等于数据频率。** getter 以 200 Hz 轮询，只证明你问得勤，不证明数据新。必须按 ID 实测到达间隔。
- **坑二：电流符号未定。** 官方协议标注 unsigned，解析代码与注释存在差异。开工前做正反方向运动、受控加载，保存原始帧，对照物理方向确认；不要凭注释推断，也不要私自改解码。
- **坑三：母线电流不是关节电流。** `0x261~0x266` 的母线电流在 1.5 kg 机型上无采样，恒为 0。

### 4.3 压测要输出的数

- 各 ID 周期中位数：应接近 20 ms。
- P95 / P99 / 最大间隔：反映抖动与丢帧。
- 超时次数：超过判据（如 >40 ms）的次数。
- 总线错误数：CAN 错误帧计数。
- 有效样本率：通过校验的样本占比。

> 验收门：六个 ID 全部有数据；周期中位数在 20 ms 附近；未发现超过 100 ms 的间隔；有效样本率 ≥99%；单位、方向、指令语义可解释；任何异常都不会静默进入训练数据。

### 4.4 产物

`raw/`、`episodes/`、`sync_report.md`、`manifest.json`。同步报告要写清判据，因为「零丢帧」在无帧序号时不可证明，只能表述为「未发现超过某判据的间隔异常」。

## 5 阶段 2：力矩尺度核验

预计 3 至 5 天（含工装）。这一步不做，后面所有 N·m 数字都没有意义。

### 5.1 先明确一件事

`τ_m = K · I_m` 里的 K 是**有效系数**，要注明是否包含减速比、效率与符号。厂家 SDK 的 `effort` 字段可作核验起点，不是本机校准证书。

### 5.2 静态差分流程

1. 固定一个受控姿态，装已知质量 `m` 的砝码，记录质心到各关节轴的力臂。
2. 空载稳态采 5 秒，得到基线电流 `I_0`。
3. 加载后稳态采 5 秒，得到 `I_1`。
4. 卸载，重复一次，观察回差。
5. 换至少 5 个姿态、3 种载荷，覆盖正反两个方向。
6. 每次记录温度与稳态等待时间。

参考力矩通过接触点雅可比映射到关节：

```text
delta_tau_ref = J_contact(q).T @ wrench
delta_tau_ref[j] ~= K[j] * (I_1[j] - I_0[j])
```

### 5.3 拟合与可辨识性

- 每个关节独立拟合 `K_j`，保留截距项并检查残差，不要逐点相除后平均。
- 竖直方向的重力配重激励不了绕竖直轴的关节，这类关节要换施力方向，否则**标为未标定**。
- 六个关节的 K 不必相近，也不强制 5% 离散度；用你自己的实验精度目标验收。

> 验收门：每个已标定关节给出 K、方向、标定区间、独立验证误差、回差；未激励关节明确标「未标定」；标定数据与最终测试数据不重叠。

### 5.4 三条红线

- 不用 MIT 模式的 `T_ref` 当力矩真值：它是控制输入，输出还受反馈项、重力、摩擦、限幅影响。
- 不用「自由空间残差贴零」证明 K 正确：缩小 K 同样能让残差变小。
- 不把参考传感器的 N 直接和关节的 N·m 相减，必须先做坐标变换与雅可比映射。

## 6 阶段 3：自由运动数据集

预计 2 至 3 天（含采集与清洗）。

### 6.1 预算

- 训练集：约 10 分钟，覆盖单关节、多关节联动、不同速度。
- 验证与测试：**另外采**，不从这 10 分钟里硬切；总量再按 8:1:1 划分。
- 人工拖动会产生外力，不能直接当自由空间标签；先记录轨迹，再在无接触时回放。

### 6.2 采集矩阵

| 类别 | 内容 | 目的 |
| --- | --- | --- |
| 单关节 | 六个关节分别低速 / 中速 / 高速往复 | 激励摩擦与方向切换 |
| 多关节 | 2 至 3 关节联动，覆盖常用工作空间 | 激励耦合项 |
| 重复路径 | 同一路径重复 5 次以上 | 检查重复性与温漂 |
| 静止保持 | 不同姿态各停 5 秒 | 检查重力项与静态偏置 |
| 极端姿态 | 接近但不超过限位 | 检查外推表现 |

速度从低速开始逐级提高，先验证自碰撞余量与停止功能。保护触发段单独记录，不要靠降低保护等级去掩盖过激轨迹。

### 6.3 质量检查

逐关节画四张图：位置、速度、跟踪误差、电流（或力矩）的分布与时间曲线。

- 某个关节几乎没被激励（例如 J6 一直被夹爪任务占住），这一维学不好，后面接触检测会漏。
- 尖峰先追溯原因（通信、保护、真实接触），不要一律平滑删除。
- 预热以漂移稳定为准，5 分钟只是起点。

### 6.4 切分与目录

先按 episode / 采集批次划分训练、验证、测试，再构窗。禁止跨段、跨集合构窗。标准化只在训练集上拟合。

```text
experiments/run_id/
  manifest.json
  raw/            # 原始帧与时间戳
  episodes/       # 解析后的信号与源时间
  splits.json     # 冻结的切分清单
  processed/      # 对齐样本与有效掩码
  calibration/    # K 与参考记录
  models/         # checkpoint 与归一化参数
  metrics/        # 预测与评估
  figures/        # 覆盖与误差图
```

> 验收门：10 分钟数据覆盖六关节；每关节都有明显的位置/速度激励；切分清单已冻结并哈希；训练集与测试集无同一轨迹。

## 7 阶段 4（L1）：NEXT 训练与自由空间验收

预计 3 至 5 天（含基线）。

### 7.1 训练闭环六步

1. 核验字段、单位、同步与有效掩码，排除接触污染与故障段。
2. 按冻结切分生成因果窗口，标签取窗口**最后时刻**的 τ_m。
3. 只用训练集拟合归一化，验证与部署复用同一组参数。
4. 按第 7.2 节参数训练，记录种子、早停与最终解析配置。
5. 用验证集选 checkpoint，测试集只评估一次。
6. 输出若做了标准化，先反变换再算物理误差。

先用 1 分钟的小数据把「训练 → 保存 → 重载 → 离线预测」跑通，再上全量。第一次排障不要同时改频率、输入、结构与滤波。

### 7.2 参数卡（PiPER 50 Hz 适配）

| 项 | 值 |
| --- | --- |
| 输入 | `[q, dq, q_cmd − q]` 的历史窗口 |
| 历史长度 | H=25（50 Hz 下约 0.5 秒） |
| 网络 | 2 层 LSTM，隐藏 128；2 层 MLP，隐藏 256 |
| Dropout | 0.1 |
| 优化器 | AdamW，lr=1e-3，wd=1e-6，梯度裁剪 1.0 |
| 损失 | MSE |
| 早停 | patience=20，warmup=10 |
| 隐状态 | 每个窗口重置，不跨窗口累计 |

注意：论文的 H=50 是 100 Hz 下约 0.5 秒，不是 1 秒；50 Hz 下取 25 点才是同一时长。降频不等于等价，记录这一差异。

### 7.3 验收指标

| 指标 | 初期工程目标 | 说明 |
| --- | --- | --- |
| 关节平均 MAE | ≤0.05 N·m | 工程目标，不是论文标准 |
| 逐关节 MAE / 偏置 / P95 | 全部报告 | 均值会掩盖单关节失败 |
| 静止 vs 运动 | 分开报告 | 静止段检验重力与偏置 |
| 推理延迟 P95 | 记录实测 | 不要引用论文的 1.76 ms |

误差定义必须写清：

```text
MAE = sum(abs(pred - ref)) / (N * J)
MAE_joint[j] = mean(abs(pred[:, j] - ref[:, j]))
```

> 验收门：独立同分布测试集达到冻结目标；逐关节指标无异常关节；测试集只评估一次；与论文 0.018 N·m 比较时，先确认平均方式、频率、物理尺度与测试条件。

### 7.4 三条禁令

- 不跨 episode 切窗，不把相邻帧分到训练与测试两侧。
- 不用测试集调阈值、选 checkpoint 或选权重比例。
- 不把插值出来的 100 Hz 当作真实带宽；电流原生只有 50 Hz。

## 8 阶段 5（L2）：接触验证

预计 3 至 5 天（含工装与标注）。

### 8.1 场景设计

用受控工装构造：短接触、持续接触、不同方向、不同姿态、不同速度。保留长时间无接触运动，避免只测容易检出的强接触。人工不得置于运动夹点，接触范围与停止条件提前写死。

### 8.2 阈值

1. 在一段独立无接触数据上算接触分数 `score = sum(abs(tau_ext))`（L1，不是 L2）。
2. 取高分位数（如 P99）作为 `T_high` 初值，`T_low` 取 `T_high` 的 0.5 至 0.7 倍形成滞回。
3. 用带标注的接触事件微调，**只在这组标定数据上调**。
4. 冻结后到另一组轨迹上测试，不得回头再调。

记录阈值、滞回宽度、最短持续时间、滤波延迟与标定数据哈希。

### 8.3 事件级指标

给每次真实接触标起止、方向、置信度。预测段与真实事件一对一匹配：未匹配的预测算误触发，未匹配的真实事件算漏检。

| 指标 | 说明 |
| --- | --- |
| 事件级 precision / recall / F1 | 主指标 |
| 每分钟误触发次数 | 无接触时长内统计 |
| 延迟中位数 / P95 | 事件起点到检出 |
| 样本级 F1 | 仅作补充，不与事件级混用 |

> 验收门：recall ≥90%、误触发 ≤1 次/分钟、延迟 P95 <100 ms（工程起始目标，按任务调整后冻结）；20 次接触只够初测，正式验收要多批次并给区间；零误报必须同时报告观察时长。

## 9 阶段 6：FIRST 标注与四组策略对照

预计数周，取决于示教采集速度。

### 9.1 逐轨迹标注

- 用冻结的 NEXT 与检测器逐 episode 跑，保留原始残差、滤波残差、分数与标签。
- `C` 接触优先级最高；每次接触起点前 1 秒（50 Hz 下 50 个样本）的非接触样本标 `PC`；其余 `FS`。
- 不跨 episode 构造 PC。开头已经接触的段可标 C，但补不出录制前的 PC。

### 9.2 采样

按样本锚点赋权，权重与阶段成比例。多数任务 `FS:PC:C = 1:5:1`，持续接触型任务（拧瓶盖）为 `1:3:3`。这是任务相关的结果，不是通用最优。

动作块长度 30 时，末尾不足的样本要么丢弃要么加 mask，不跨轨迹拼接。固定训练步数与抽样总量，否则「重采样有效」会被「训练更久」污染。

### 9.3 四组对照

| 组 | 力矩输入 | FIRST 重采样 |
| --- | --- | --- |
| A 基础 | 否 | 否 |
| B 仅力矩 | 是 | 否 |
| C 仅重采样 | 否 | 是 |
| D 完整 FIRST | 是 | 是 |

四组共用示教、视觉处理、基础架构、训练预算与评估分布。C、D 用同一个冻结 NEXT 的标签。

### 9.4 评分

训练前固定阶段划分与计分规则；报告整任务成功率与阶段进度；每策略每任务至少 20 次 rollout，至少 3 个训练种子起步；成功率给二项区间。理想情况下盲评。

> 验收门：四组都跑完、预算是同一量级、测试集未参与选型；结论允许「不确定」或「未观察到收益」。

## 10 阶段 7（可选）：力反馈遥操作

这条分支不阻塞 FIRST 实验。前提是有一台能主动施力的主臂；被动位置读数装置靠软件变不出力反馈，原厂主从设置也不等于论文的力反馈系统。

先检查主从方向、关节映射、力矩限幅、通信延迟与失联行为，再低增益验证。看门狗、阻尼、渐入、急停要独立测试。只有新鲜且有效的估计才能进入反馈回路。

## 12 故障速查

| 现象 | 优先检查 | 处理 |
| --- | --- | --- |
| 残差量级明显不对 | mA 与 A、度与 rad、K 与符号 | 回查原始帧与已知载荷 |
| 残差贴零但接触测不出 | K 是否被缩小、分数是否用了 L2 | 重新标定，改用 L1 求和 |
| 静态偏置随姿态变 | 负载、标定姿态覆盖、模型范围 | 扩姿态重标，不用单常数掩盖 |
| 测试误差低得可疑 | 重复轨迹、跨段窗口、尺度 | 审计切分与物理单位 |
| 接触后残差塌陷 | 保护、限幅、真实脱离 | 标事件，保留原始信号 |
| 长时漂移 | 温度、负载、隐状态重置 | 检查重置策略，必要时重训 |
| 每小时误触发过多 | 阈值、滤波、噪声相关性 | 冻结参数重标，延长观测 |
| FIRST 无提升 | 标签、训练预算、任务瓶颈 | 看四组对照与区间，别急着调权重 |

降频或硬件差异导致误差变化，不自动推翻论文；自由空间误差低也不自动支持全部结论。
