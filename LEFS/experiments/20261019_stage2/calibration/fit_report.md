# S2-1 力矩常数 K 标定报告

- 方法：**同姿态「空载 − 带载」差分**，`ΔI_j = τ_pay,j(c6)/K_j + δ_j`
- 载荷：水瓶 0.525 kg（连瓶带水带胶带，刚性固定在夹爪上，随腕部倾斜）
- 姿态数：10 对；静止段取最后 30 s
- 为什么这个口径可信：τ_pay **只依赖运动学 + 已知质量 + 未知质心 c6**，与 URDF 连杆质量无关；臂自重、固件重力前馈、连杆质量误差在差分里整体抵消
- 判据：`τ 跨度 ≥ 6·|K|·σ_I` 且 `σ_K/|K| < 30%`，否则写「未标定」，不填 SDK 系数
